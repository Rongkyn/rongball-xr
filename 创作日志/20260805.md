# 创作日志 2026-08-05

## 今日作品：「萤火虫花园」
**类型：** 互动网页 · Canvas
**路径：** `创作时间/20260805/firefly_garden.html`

### 创作思路
昨天完成了即梦治愈日常系列60张选片后，今天想换一个方向——从静态AI生图转到互动编程创作。灵感来源是昨晚想象的画面：深夜的花园，有萤火虫飘浮，你点击屏幕就能种出发光的花。

### 技术实现
- 纯 HTML/CSS/JS，单文件，零依赖
- Canvas 2D 渲染，包含以下系统：
  - **花朵系统**：点击种花，花瓣以粒子绽放动画展开，每朵花随机配色（7种色调盘）、随机花瓣数（5-8瓣）、随机茎高
  - **萤火虫系统**：25只萤火虫漫游，暖黄-暖绿色调，呼吸式发光
  - **草地系统**：程序化生成的草地，随风轻摆
  - **星空系统**：闪烁星星 + 随机流星
  - **月亮**：带光晕和环形山纹理
  - **鼠标光迹**：移动时留下柔和发光粒子
  - **诗意文字**：花开到里程碑数量（5/12/20/30...）时触发10首短诗
- 支持触屏操作
- 花朵有生命周期：绽放→发光→60秒后慢慢淡去→消失

### 设计特点
- 暗色基调（深蓝黑），花朵暖光形成对比
- 远山剪影 + 草地层次营造景深
- 所有运动使用正弦函数，自然有机感
- 文字极简，不抢视觉主体

### 创作感受
写 Canvas 粒子系统的时候觉得很有禅意——每个粒子都有自己的生命周期、颜色、轨迹，但最终组合成一个和谐的画面。和萤火虫花园的意境很搭。
