## 今日产出

### 🌌 星野 · Starry Field - 全新互动体验

**项目路径：** `rongball-xr/xr/starry-night.html`
**代码量：** ~600行

**在线地址：** https://rongkyn.github.io/rongball-xr/xr/starry-night.html

**创作灵感：**
"星野"取自中国古代天文概念——将天空星区与地理区域对应，仰望星空即是俯瞰大地。
灵感来源：苏州石刻天文图、二十八星宿、"天似穹庐，笼盖四野"。

东方美学互动系列的"天"篇——与水墨山水（山）、枯山水（砂）、鱼乐（水）构成天地对应。

### 操作方式

| 操作 | 效果 |
|------|------|
| 移动鼠标 | 星空视差 |
| 点击星座区域 | 高亮星座 + 显示名称 + 和弦音 |
| 点击空白处 | 微弱涟漪扩散 |

| 按 N | 切换星名标注 |
| 底部按钮 | 同上功能 |

### 技术亮点

1. **三层视差系统**：星星按layer属性分三层，鼠标移动时产生不同偏移量，模拟景深
2. **银河生成**：沿对角线分布2000个粒子，用高斯叠加（3个random减1.5）偏离中心线，形成自然带状
3. **月相系统**：8个月相通过bezierCurveTo绘制遮罩边缘，模拟真实月球盈亏过程
4. **流星尾迹**：维护30帧的trail数组，渐变透明度和宽度，头部有径向光晕
5. **星名系统**：预置二十八星宿名 + 北极星/织女星/牵牛星等经典星名
6. **程序化山形**：多层sin叠加（不同频率和相位）+ max函数产生山峰突起，形成自然远山剪影

### 设计思考

1. **天地呼应**：东方美学系列终于有了"天"——水墨山水是山，枯山水是砂，鱼乐是水，星野是天
2. **东方星图**：没有用西方星座（猎户座/大熊座），而是用中国星官体系（北斗/织女/牵牛/二十八宿），更贴合整体东方美学方向
3. **克制与沉浸**：没有工具栏/侧边栏，全屏星空+底部极简按钮，让用户沉浸在黑暗中
4. **知识彩蛋**：每个星座点击后有文化背景说明，月相有中文古称（朔/望/上弦/晦）
5. **声音设计**：每个星座对应一个和弦音（C D E F G A），点击时触发，像星星在"应答"
