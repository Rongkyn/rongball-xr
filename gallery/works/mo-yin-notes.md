## 一句话

宣纸上一滴墨的洇散全过程：落墨、湿锋推进、宽淡晕、水痕线，水尽墨定——一件「会完成」的作品。干后定格，再点即继续落墨，双击清纸。

## 场景

无固定物象，主体是单团 / 多团墨在纸上的真实晕染行为：焦芯饱满、外缘一圈清晰水痕线（tide line）、宽而透的淡晕、纤维横丝肌理、自然毛茬边缘。暖灰淡墨、宣纸底。

## 交互

- **点落一团墨**；**拖扫连续落墨**。
- **水尽墨定自动定格**（会完成）；再落墨使画面复活；**双击清纸**。

## 物理 / 绘制要点（四场，抛弃反应项）

- **W 水场**：9 点 Laplacian 纯扩散（D=0.38）+ 蒸发 2.8e-5，沿纤维通道差异调制；水前锋即湿锋。
- **P 悬浮色素场**：只在水量充足处迁移（迁移率 ramp 于 W∈[0.008, 0.09]，毛细挂墨、水干即挂住）+ **平流 ADVEC 随水流（咖啡环机制，水量闸门 ADVEC_W=0.45，只在薄水发力）**。
- **S 沉积场**：基础吸附 × 纤维 + 锋线窄带钉线（峰值 w≈0.05 抛物带）+ 水干急速挂墨；沉积不可逆 = 落墨不悔。
- **F / F2 纸纤维场**：低频值噪声帘纹 + 高频锐化纤维通道，同时调制扩散 / 蒸发 / 沉积三端。
- 焦芯锚定：落墨即按约三成比例瞬时入纸，等效真实纸面瞬时吸墨，是防面包圈的最简机制。
- 淡墨用暖灰；v10 做横丝去方向性（防印刷感）+ 前锋扰动 0.9 定格。

## 参照系 / 立项目标

直接对标昨日（墨散）专家视角的失分项，逐条给机制：

| 水墨特征 | RD 版失败原因 | 本模型机制 |
|---|---|---|
| 宽淡晕 | 斑图特征波长锁死晕宽 | D_w ≫ D_p，水远色素稀 → 自然淡晕 |
| 水痕线 | 梯度加成救不回 | 锋线吸附暴增（tide line 物理） |
| 毛茬边缘 | 扰动即失稳 | 静态纤维场调制扩散，稳定系统不怕扰动 |
| 焦芯 | 靠 Beer-Lambert 调色 | 落点浓度高 → 沉积多 → 自然近黑 |

## 本轮调参记录（v1–v10，一版一帧可溯）

1. **v1–v2**：合成事件 `setPointerCapture` 报错，try/catch + lastP 守卫修复。
2. **v3**：斑点不扩散——水量预算过少。确立「**水量标定是扩散表演第一参数**」：峰值需在表演全程高于锋线阈值。
3. **v4**：水量 + EVAP 修正后出宽淡晕，但出现面包圈（初始落墨边缘 tide 发力 + 内部色素流失）。
4. **v5**：tide 闸改薄水窄带 + 落墨三成瞬时入纸锚定焦芯 → 焦芯饱满；淡墨改暖灰。
5. **v6**：加平流 ADVEC 0.6 且无闸门 → 抽空墨芯、笔画出双轨线（面包圈回归）。
6. **v7**：平流加水量闸门 ADVEC_W=0.45（厚水处无平流）→ 墨芯恢复、外线初现。
7. **v8**：锋线窄带钉线（w≈0.05 峰值）+ F2 锐化成纤维通道 → 外缘线清晰、内部见横丝。
8. **v9**：蒸发沿纤维通道差异（前锋破形的直接杠杆：前锋处 LB 小，调制扩散率不如调制蒸发）→ 边缘出毛刺。
9. **v10**：横丝去方向性（防印刷感）+ 前锋扰动 0.9 → 定格。

## contribution（可复用）

1. **方向证实（最重要）**：纯扩散 + 毛细模型说出水墨晕染语言。与墨散合起来得到「**模型选语言，调色救不了模型**」——RD 版 23 轮调色无效，换模型 10 轮达标。
2. **咖啡环平流须配水量闸门**：solute advection 在厚水处会抽空墨芯（v6 实锤）；物理上蒸发驱动流只在前沿显著，ADVEC_W 闸门是必要项。
3. **前锋破形第一杠杆是蒸发端不是扩散端**：前锋处 Laplacian 小、调扩散率绝对量小，蒸发直接决定前锋存活 / 钉扎位置。与墨散「RD 扩散端扰动危险」判据互补：纯扩散系统无条件稳定，扩散 / 蒸发 / 沉积三端扰动全部安全。
4. **焦芯锚定**：落墨按比例瞬时入纸（约三成）防面包圈的最简机制。
5. **水量标定公式**：水峰值 p(t)=M/(2πσ²)·e^(−EVAP·t) 需全程大于锋线阈值 θ，否则中途「断水」停滞（v3）；扩散半径上限 R≈σ·√(2 ln(p/θ))。
6. **可复用资产**：mo-yin.html 四场晕染引擎（12KB 零依赖），水 / 色素 / 沉积 / 纤维场结构可直接服务后续水墨小品。
