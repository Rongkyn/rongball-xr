# 墨竹 v11.2 竿身笔触感调参日志

- 文件：`gallery/works/ink-garden.html`
- 备份：`ink-garden.html.bak-v11.2-first`（opacity 0.88 / spacing 0.10 的初版）与当前修复前的 opacity 0.62 / spacing 0.16 版本
- 测试：`cdp_capture.py`（全图）+ `cdp_closeup.py`（左侧主竿特写，300,200,350×700 @2x）
- 结论：最终采用 **湿笔骨架 + 干笔颗粒双 pass + 随机抖动 + 加强飞白刮丝** 的组合，主竿 median dark 由 72.7 降到 38.3，纸底露白率由 36.3% 升到 41.7%，纵向高频纹理 hf_v 由 8.20 升到 8.93，三段墨色仍可辨（中浓最暗 dark=77.9，根焦 60.8，梢重 37.7）。

## 关键代码改动

1. `brushPath` 增加可配置参数并加入笔触随机性（默认值保持原行为，不影响兰/枝/叶）：
   - `opts.szMul`：stamp 绘制尺寸系数（默认 1.5）
   - `opts.jitter`：垂直走笔方向的法向抖动
   - `opts.seed`：铺贴随机种子
   - 每个 stamp 引入：
     - 法向位置抖动 `±0.5·w·jitter`
     - 旋转抖动 `±0.06·jitter rad`
     - 尺寸随机 `0.86–1.16·szMul·w`
     - 不透明度随机 `0.78–1.12·opacity`
     - 采样位置加入 `0.25–0.75` 的随机相位，避免等距节律

2. 新增竿身专用 stamp（不改兰/枝/叶的全局 stamp）：
   - 湿笔 `stalkStamp / stalkStampNong / stalkStampZhong`：feather 0.50–0.54，dryness 0.30–0.34
   - 干笔 `stalkDry / stalkNongDry / stalkZhongDry`：feather 0.66–0.68，dryness 0.62–0.64

3. `drawBambooStalk` 三段架构保留（焦→浓→重），每段改为双 pass：
   - 湿笔骨架：opacity 0.48，spacing 0.24，szMul 1.30，jitter 0.18
   - 干笔颗粒：opacity 0.30，spacing 0.30，szMul 1.18，jitter 0.40

4. 加强 destination-out 飞白刮丝：
   - 每段 5–7 条（原 3–4）
   - 起点 0.08 + fi·0.14（原 0.15 + fi·0.20），分布更均匀
   - 长度 18%–40%（原 12%–24%）
   - alpha 0.16–0.38（原 0.08–0.20）
   - 线宽 0.5–1.7，dash 间隔加大
