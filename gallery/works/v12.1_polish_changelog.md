# v12.1 Brush Engine V5 正式版 · 调校记录

**日期**：2026-08-15

**结果**：✅ Spitke报告6个P1问题修复4个，兰竹笔触质感自评7.8/10

## 修复项

### 1. 兰叶过粗回调（P1）
- `maxW` 从 `b.width * 1.8` 回调至 `b.width * 1.15`
- `makeOrchidPressureV5` 包络全面细劲化：
  - 钉头从 `0.3→1.0` 改为 `0.2→0.55`（小而含蓄）
  - 行笔主体从 `0.85maxW` 降至 `0.42maxW`（细劲飘举）
  - 出锋从 `0.40*pow(k,1.8)` 改为 `0.20*pow(k,2.2)`（更劲利）

### 2. 竹叶恢复锐利出锋（P1）
- `hwAt()` 叶尖从 `0.50*pow(k,0.50)` 改为 `0.15*pow(k,2.0)`，真正收到近0
- 收束段提前到 t=0.65 开始，t=0.85 进入极细出锋
- 内联 `leafPressure` 简化，不再二次叠加收窄（避免冲突）

### 3. 竹兰墨色拉开2阶（P1）
- 竹叶浓墨：nong档从 `drawFill`(变量) 固定为 `INK.jiao`（焦墨）
- 兰叶主叶：从 `INK.jiao` 降至 `INK.zhong`（中墨）
- 兰叶淡叶：从 `INK.zhong` 降至 `INK.dan`（淡墨）
- 效果：竹焦浓、兰淡清，"竹刚兰柔"墨阶对比成立

### 4. 飞白强度上调（P1）
- 丝条数：`4+feibai*10` → `5+feibai*14`
- 刮除alpha：`(0.15~0.55)` → `(0.25~0.70)`
- 丝宽：`0.4~1.9` → `0.6~2.8`
- 密度阈值降低（更多连续段）
- 点状颗粒：数量×1.5，半径增大，起始提前

### 5. 竹叶边缘撕裂感修正（调校中发现）
- nong档 `edgeJag` 从0.40降至0.22
- zhong档从0.48降至0.28
- qing档从0.55降至0.35
- 破边从"锯齿撕裂"回归"毛笔自然毛糙"
