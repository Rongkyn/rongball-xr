## A. `buildBamboo()`（约 1365-1650 行）

### A1. `stalkCount` 上限 2 → 3（line 1377）

```diff
- stalkCount = Math.max(1, Math.min(2, stalkCount|0));
+ stalkCount = Math.max(1, Math.min(3, stalkCount|0)); // v12.0 P3: compose 支持三竿
```

dispatch 传 `stalkCount:3` 时主竹将生成"主+辅+梢"三竿（在同一 plant 内），这是 P3 截图验收所要求的三竹构图；非 compose 模式仍保持原有 1-2 竿逻辑。

### A2. 雀爪细枝数 2-3 → 1（line 1599）

```diff
- const subN = 2 + (rand(s*93+ni) < 0.5 ? 1 : 0); // 2-3 根
+ const subN = 1; // v12.0 P3: 每枝仅1雀爪细枝，1雀爪叶簇
```

每根主枝只保留 1 个雀爪细枝 → 1 个雀爪叶簇，配合 A3 删除中段雀爪，叶量从 200+/竿 降到目标区间。

### A3. 删除"长枝中段雀爪"整块（原 1628-1660 行附近）

P2-fix 加的"长枝(>120px) 中段 40-60% 处额外加 2 根细雀爪、60% 概率"整块**完全删除**。该块是当前叶量超标的主要来源之一（每根长枝多生 2 个中叶簇），且与"每出枝点 1 主叶簇 + 雀爪 1 叶簇"的 P3 铁律冲突。

### A4. 保留的叶簇调用（line 1621、1627）

- line 1621：雀爪端 1 个 `sub` 叶簇（A2 改为 1 根细枝后只剩 1 个）
- line 1627：主枝端 1 个 `main` 叶簇

贴根叶簇、30%/75%/18% 中叶簇在 P2 已删除，本次确认未恢复。**叶子只生在小枝末端。**

### A5. 梢头小叶改为字法叶簇（line 1633-1648）

```diff
- leafGroup: 'ren', leafCount:[3,5], leafLenMin:38, leafLenMax:56
+ leafGroup = rand()<0.5 ? 'ren' : 'ge'
+ leafCount: ren→[2,2] / ge→[3,3]
+ leafLenMin:36, leafLenMax:52, clusterType:'sub'
```

这是主竿的"雀爪 1-2 簇"——每竿顶 2 簇（ren/ge 随机），即 2-6 片顶叶。

## B. `_addBambooLeafCluster()`（line 1652-1687，整函数重写）

### B1. 字法分布：ren 30% / ge 50% / jie 20%

```js
if (r < 0.30)      { groupType='ren'; lcMin=2; lcMax=2; }
else if (r < 0.80) { groupType='ge';  lcMin=3; lcMax=3; }
else               { groupType='jie'; lcMin=4; lcMax=(main&bl>100)?5:4; }
```

删除旧的 `isTip→ren(3叶)` / `sub→ren/fen(4叶)` / `main→ren/fen/ge(5-7叶)` 分组，以及 `fen/tip` 类型（drawBambooLeaves 也一并删除对应分支）。

### B2. 叶长 38/56 → 40-70（compose）

```diff
- baseLen = main?42:38; maxLen = main?58:56;
+ baseLen = main?48:40; maxLen = main?70:58;
```

`sizeMul` 仍按 `clusterType×bl` 缩放；`isMain` 系数 0.95→0.92（辅/远竿略小）；实际尺寸：

- 主枝：48×(0.88~1.10) ~ 70×(0.88~1.10) ≈ **42-77px**，主带落在 48-70
- 雀爪/侧枝：40×(0.85~0.95) ~ 58×(0.85~0.95) ≈ **34-55px**，主带 40-58
- 远/小叶（梢头 ren/ge）：36-52，落在 32-48 区间附近

### B3. clusterType 字段透传

新增 `clusterType: clusterType || 'sub'` 写入 branch 对象，供 `drawBambooLeaves` 判定是否允许清墨（仅 sub 且 10% 概率）。

### B4. forkSpread 微调

`0.85 + rand*0.15` → `0.80 + rand*0.12`，让字法夹角更紧凑（40-70°）。

## C. `drawBambooLeaves()`（line 1964-2300，整函数重写）

### C1. 字法 offsets 重写（line 1979-1983）

```js
ren(2叶): [-0.55, 0.60]                       // 一左一右，夹角 ~66°
ge(3叶):  [+0.10, -0.78, +0.82]                // 一上 + 左下 + 右下
jie(4-5叶): [+0.10, -0.78, +0.82, -0.35, +0.40] // 个 + 两片侧叶
```

所有 offsets 统一乘 `sideSign`（每簇 15% 概率整簇镜像翻转形成顾盼）。删除旧的 `ren:4 叶 [0,-0.7,0.75,0.22]` / `fen:5 叶` / `tip:4 叶` / `ge:7 叶` 数组。

### C2. 字法主笔长短 / 墨色档（line 1986-1998）

```js
mainFactors: ren[1.05,0.88] / ge[1.15,0.92,0.96] / jie[1.15,0.92,0.96,0.72,0.70]
tonePlan:     ren[nong,zhong] / ge[nong,zhong,nong] / jie[nong,zhong,nong,dan,dan]
```

主笔最长最浓，副笔重墨，侧叶淡墨。删除旧的"n=0 主笔 1.10、n≤2 副笔 0.60、n≥3 外层 0.48 + 随机墨色"逻辑。

### C3. 长披针形宽度（line 2047-2049）

```diff
- maxHalf = len * (0.095 + rand*0.012) * sm   // 旧：约 0.095-0.107（尖矛）
+ halfWRatio = (n===0 ? 0.16 : 0.13) + rand*0.02
+ maxHalf = len * halfWRatio * sm              // 新：0.12-0.18
```

对应宽度比 0.24-0.36（半宽 × 2），落在 P3 要求 0.12-0.18 的全宽系数区间。

### C4. 宽度包络 hwAt 重写（line 2083-2090）

```js
t<0.06: 0.30 → 0.85（叶基圆钝缓起）
t<0.30: 0.85 → 1.00（最宽在 ~t=0.30）
t<0.85: 1.00 → 0.55（中段缓收）
t≥0.85: 0.55 * pow(k, 0.7)（最后 15% 急收为锋线）
```

旧版最宽在叶基 t=0.06-0.18（1.0），之后线性收到 t=0.88 的 0.10，再线性收尖——形状像折纸/尖矛。新版最宽在 1/3 处，叶尖急收，是典型的长披针形。

### C5. C 形弧弯（line 2063-2071）

```diff
- const curve = 0.22 + ageFactor*0.38 + rand*0.12;  // 旧：12-34°（偏大且每叶独立）
+ const curveBase = 0.08 + ageFactor*0.10;            // 5-10°
+ const curveOuter = (n>=3) ? 0.08 + rand*0.08 : 0;   // 外层最多 +10°，合计 ~20°
+ const curve = (curveBase + curveOuter) * sideSign;   // 整簇同向
```

- 所有叶弧弯方向由 per-cluster `sideSign` 统一决定，不再每叶 `rand` 左右乱摆
- 单方向 C 形，不是 S 弯（中心线用二次贝塞尔，控制点向 sideSign 方向凸 6% 叶长）
- 老叶/外层（n≥3）可到 15-20°

### C6. 折叶比例 12%（line 2006）

```diff
- const foldChance = b.isTop ? 0.15 : 0.42;
+ const foldChance = 0.12;
```

- 所有叶统一 12%，删除 isTop 特殊档
- 折叶**背面强制淡墨** INK.dan（line 2027-2030），不再保留原墨色
- foldAngle 从 0.55-0.80 收到 0.45-0.65（折叶更自然）

### C7. 叶柄（line 2059-2062 + 2130-2138）

每片叶基前画 3-5px 细线，颜色 INK.zhong，宽度 0.8-1.2px，连接枝点到叶片起点。删除旧的"baseOff 叠压抱枝"副笔 6-8px/外层 10-14px 偏移（那是旧版无叶柄时的 hack）。

### C8. 中脉（line 2232-2245）

```diff
- if (len > 30 && n === 0) { alpha 0.20; INK.jiao; 宽 maxHalf*0.10 }
+ if (len > 55 && (n===0 || leafTone==='nong')) {
+   alpha = 0.35 * a; color = INK.zhong; lineWidth = 0.5;
+ }
```

仅大叶（>55px）/前景浓墨叶画中脉，颜色从中墨（不是焦墨），alpha 0.35，宽度固定 0.5px（细而淡）。

### C9. 叶簇间距（line 2051-2057）

```js
const alongShift = n * (3 + rand*3);  // 每片叶沿枝方向前移 3-6px
const sx = lx + bcos*alongShift + ppx*perpOff;
```

旧版 `startOff = n*0.6 + baseOff*0.5` 最大只有 ~10px 且主要在 n≥1，且 baseOff 是叠压用的。新版每片叶均匀沿枝错开 3-6px，叶簇之间不再全部从同一点放射。

### C10. 墨色分级与清墨占比 ≤10%

```js
nong: INK.nong / jiao tip / opacity 0.94
zhong: INK.zhong / nong tip / 0.86
dan: INK.dan / zhong tip / 0.74
qing: INK.qing / zhong tip / 0.62   // 仅 clusterType='sub' 且 rand<10% 且 n>=3
```

- 鲜绿：代码里从未出现，确认无
- 清墨占比通过 `isQingAllowed = clusterType==='sub' && rand<0.10` 硬限制 ≤10%，且只在侧叶（n≥3）出现
- 折叶背面强制 dan（覆盖 tonePlan）

### C11. 叶尖出锋线收窄（line 2218-2230）

```diff
- if (len > 30 && leafTone==='nong' && n<=2)
+ if (len > 40 && leafTone==='nong' && n===0 && !doFold)
```

只给主笔（非折叶）画出锋线，避免副笔也抢焦墨尖。线宽 maxHalf*0.08（旧 0.08 同），长度从 0.8 maxHalf 收到 0.9（稍长一点）。

### C12. 飞白减弱（line 2248-2280）

```diff
- 概率 20%，nStreaks 1-3，alpha 0.10-0.22
+ 概率 15%，nStreaks 1-2，alpha 0.08-0.18
```

长披针形叶片比旧版宽，飞白过强会显脏；减弱后保留 v9.9 笔触感但不抢主形。

### C13. 采样密度 24 → 28

`N = 28`（旧 24），长披针形曲线更平滑。

### C14. strokes 上限 7 → 5

```diff
- strokes = Math.max(3, Math.min(7, strokes|0));
+ strokes = Math.max(2, Math.min(5, strokes|0));
```

字法最多 5 叶（jie），且 ren 可以 2 叶（旧版强制 ≥3 会把 ren 撑成 3 叶）。

## G. 已知遗留 / v12.1 候选

- brushPath 笔触化叶片（P3 铁律明确留 v12.1，当前仍走 fillPath+渐变）
- 清墨（INK.qing）实际渲染效果需在暖宣底上肉眼复核（规格警告"淡墨浅褐在暖宣低对比"是已知陷阱）
