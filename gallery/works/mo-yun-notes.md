## 一句话

一张宣纸，点击落墨，墨晕扩散的同时琴弦拨动：横向位置定音高（五声音阶），纵向位置定力度。画即曲，曲即画。

## 场景

暖调宣纸底（#e8dfc8 纤维 + 暖晕光），五层墨色（清→焦）、胭脂点缀、朱红印章、宋体标题。不点击的区域是纸的呼吸（留白即休止）。古琴减字谱的空间感是立意锚点：音不只是时间序列，也是纸上位置。

## 交互

| 输入 | 映射 | 视觉反馈 | 音频反馈 |
|------|------|----------|----------|
| X 坐标 | 五声音阶音高（C3–A4，10 音） | 弦在对应高度闪烁 | 对应音高拨弦（低音在左、高音在右） |
| Y 坐标 | 力度 0.3–1.0 | 墨色五档、墨点大小、溅墨数量 | 音量 + 泛音层 |
| 点击 | 落墨 | 有机形墨晕 + 涟漪 + 弦段振动 | KS 拨弦 + 卷积混响 + 立体声 Panner |
| 空格键 | 随机落墨 | 同上 | 同上 |
| 清纸按钮 | 清除所有墨痕 | 纸归白 | — |
| 微风按钮 | 环境风粒子 | 微粒随风飘 | — |

移动端可用（pointer events）。

## 物理 / 绘制要点

- **Karplus-Strong 拨弦合成**：噪声填充延迟线 → 平均滤波循环；阻尼系数 0.995–0.9995（高音衰减快、低音延音长），三角波激励模拟近岳山拨弦。
- **泛音层**：velocity > 0.45 叠一只高八度 KS 弦，模拟泛音。
- **卷积混响**：自生成 2.5s 指数衰减脉冲响应，约 25% 湿声；立体声 Panner 按 X 给声像。
- **墨滴渲染**：24 点有机多边形（三层正弦叠加变异）+ 径向渐变（焦核→墨身→晕染边缘）+ 飞溅小点；高力度焦核近 #0f0d0a。
- **弦振动可视化**：只画拨弦点附近 35% 屏宽的局部弦段，三角形包络衰减，0.4s 视觉消退，**远快于音频延音**（音画同步的关键判据，见 contribution）。
- **宣纸底**：离屏 canvas 预渲染 256px 噪声 tile + 暖色晕光，静态背景每帧只 drawImage。
- DPR 上限 2。

## 验收（puppeteer 亲验，2026-08-20 补做）

实际用 puppeteer 打开作品、模拟 15 次点击（覆盖 X 轴音高 + Y 轴力度变化），落盘证据：

- `gallery/works/moyun-01-initial.png`：初始宣纸；
- `gallery/works/moyun-02-played.png`：多枚墨滴 + 焦核 + 飞溅 + 涟漪；
- `gallery/works/moyun-03-closeup.png`：墨滴特写；
- `gallery/works/moyun-demo.gif`：8 次点击操作动图（12fps），可见落墨→墨晕扩散→琴弦瞬间闪烁。

亲验结论与自评一致：弦振动 0.4s 消退在动图中只是一闪（确实快于音频延音，音画同步判据成立）；快速连弹多弦段叠加略杂；X 轴无音名提示需探索；力度五档（焦浓重淡清）截图可辨，高力度焦核明显。

## 本轮调参记录（v1→v5）

1. **v1 草稿**（744 行）：KS 音频 + 墨滴 + 全屏弦 + 涟漪 + 虚线连接 → 弦线像乐谱、涟漪杂乱、连接线像网格。
2. **v2**：修 P0 死代码 drawPaper→drawPaperFull；弦 alpha 改 life²、局部段收至 35% 屏宽；移除连接线；涟漪减半 → 弦不再横贯全屏。
3. **v3**：弦衰减 3.5s→0.4s（视觉快于音频）；弦加 glow；墨滴缩小、飞溅减少 → 弦成为瞬间闪烁。
4. **v4**：墨滴加深（焦墨核 #0f0d0a）、opacity 提升；弦段缩到 35% → 墨色有焦浓重淡清层次。
5. **v5 终稿**：涟漪 opacity 降到 0.1、半径缩小 → 更含蓄。

另记录一条 headless 踩坑：虚拟时间（`--virtual-time-budget`）不推进 requestAnimationFrame，弦振动截图会卡在最亮帧；交互作品截图验证须用真实 async wait，不能用 virtual-time。

## contribution（可复用）

1. **作品本身**：可交付的交互式视听小品，古琴音色 + 水墨美学结合。
2. **工具级模板**：KS JS 合成模板（噪声激励 + 平均滤波 + 动态阻尼 + 泛音层 + 卷积混响），后被绒丝复用、沉淀进音频资产；墨滴渲染函数（有机多边形 + 径向渐变 + 焦核 + 飞溅）可提取为 Ink Builder 模块。
3. **审美判据（Studio 级）**：音画同步的关键是视觉消退必须远快于音频延音，听到 3 秒的音不等于看到 3 秒的弦振，视觉是「事件标记」、音频是「回响」；交互水墨里留白不是空无，是等待被触碰。

## 待主人 / 已知边界（自评「失」四条）

- 快速连弹（10 音）时弦段叠加仍可能偏杂（真实使用 0.4s 消退，但密集时略乱）。
- 缺音阶视觉参照：顶部 9 个 tick 太微弱、无音名标注，新手需探索。
- 墨点形状单一（圆形有机变体），无长笔触、飞白等笔法。
- 无旋律引导 / 录音回放，只能即兴。
- 可能方向：hover 显音名、录音回放（Command Bus 天然支持 Event 记录）、长按拖笔长笔触、WebXR 空间音频版（与 VR Soundscape 呼应）、KS 模块提取为 Ink Builder 稳定资产。
