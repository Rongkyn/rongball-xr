## 立意
一枝老梅，雪落无声。观者寻得暗红花苞，点之即开；九萼俱发，题诗自现、印章落朱——
「遥知不是雪，为有暗香来」。寻梅的"寻"是交互本体：花苞小、色敛，须俯身细寻。

## 形制
- 单文件 HTML 零依赖，704×704 立轴，宣纸底（纤维+斑驳+顶部凉夜渐层）
- 梅枝：递归折线骨架（主干斜势角 clamp -1.0~-0.45rad，子枝禁下垂 clampUp），
  主笔+双 pass 枯笔擦+节瘤；花苞按间距疏剪保底 7–9 枚
- 积雪：骨架离屏 mask（枝干+地面）→ 雪花逐帧碰撞 maskAt → 椭圆叠加入积雪层，
  枝头雪只落上表面（aboveEmpty 判定 + 0.25 侧粘概率）
- 梅：五瓣贝塞尔没骨，径向渐变四色朱，九丝蕊+金粉药；点开 1.3s  ease-out 绽放
- 全开揭示：王安石句双列竖排自右读 + 绒球印章落朱；此后落瓣余韵（6.5s/片）
- 声：棕噪风声（bandpass 380Hz 随 gust 调制）+ 花开磬音（五声音阶 sine，1.8s 衰减）
- 风：滑杆 ±3 + 阵风正弦 + 鼠标横推瞬时风；雪花横向受力随深度分层
