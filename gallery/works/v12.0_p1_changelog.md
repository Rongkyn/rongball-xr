# v12.0 P1 竿节重写 Changelog

## 改动范围
仅改竿和节，不动枝/叶/构图/其他物种。

## 具体改动

### 1. 节数（~1389行）
- 主竿：10-13节 → 12-16节
- 辅/远竿：8-10节（不变）

### 2. 节间距正弦曲线模型（~1399-1415行）
- 旧：weights线性递减 1.80→0.20
- 新：
  - t<0.15（基部）：minLen*(0.3 + t/0.15*0.7)，基短
  - 0.15≤t<0.55（中部）：minLen→maxLen 正弦曲线，中长
  - t≥0.55（梢部）：maxLen*(1-((t-0.55)/0.45)*0.7)，梢短
  - minLen=baseW*2.5, maxLen=baseW*10
  - ±10%随机扰动
- 归一化到totalH，保证总高度不变

### 3. 锥度（widthAt, ~2546行）
- 旧：1.0→0.64（约1.56:1）
- 新：taper=1.0-0.75*t（约4:1），叠加局部肉感函数

### 4. 节环渲染（~2680行）
- 旧：destination-out刮白（擦掉竿身铺贴）+ source-over弧
- 新：
  - 去destination-out
  - 下环：浓墨rgba(26,22,18,0.85)，线宽nodeW*0.20，quadraticCurveTo弧
  - 上环：重墨rgba(44,36,28,0.70)，线宽nodeW*0.14，quadraticCurveTo弧
  - 鹊爪短线：alpha从0.62降为0.50

### 5. 竿身姿态（~1421-1439行）
- 旧：ca累积sp.curve漂移产生S弯
- 新：
  - 非梢端：ca=baseAngle+(rand-0.5)*0.004（极微顿挫不累积）
  - 梢端最后2-3节：向lean方向线性递增加"点头"5-13°
  - wobbleY从1.4降为1.2
