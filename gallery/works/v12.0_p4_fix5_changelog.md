## 结果判定

### 已满足

- 三竿不再挤作一团：layout.x 均拉开到约 400 / 900–970 / 1100–1175。
- 竹丛总跨度均 > 600px（734–783px）。
- 主竹角度均在 11–14°，辅竹角度均在 -11～-15°，主/辅欹势明显。
- 远竹保持藏竿露梢，竿长更短且 baseYOff 下移。
- 四个 seed 的 console 无运行错误。
- 右侧 65% 以后画面几乎仍有墨迹覆盖（96–100% 采样列有墨迹），但这主要来自枝叶/远竹分布，不等同于留白达标。

### 未达到 fix5 目标

关键目标“主竹顶 x 和辅竹顶 x 差距 < 80px”未达到。四个 seed 的实际竿顶差距为 307–358px。

主要原因是当前竿身高度模型中：

- 主竹实际竿长约 602–653px；
- 辅竹实际竿长仅 221–284px；
- 即使 `leanAngleBoost=0.80` 已让主/辅角度达标，辅竹因 `hScale=0.60–0.75` 与 `hMul≈0.73–0.84` 的高度组合，竿顶仍停在 y≈610–670、x≈840–910，无法上升到主竹顶 x≈530–570 附近。

因此，按“只改指定 7–8 行、不动 mainLean/subLean/farLean/hScale”的约束，fix5 不能实现顶部 x 交汇；若要达成 <80px，需要后续允许修改辅竹高度体系（例如提高 sub 的 `hScale` 或 subHMul），而不是仅调整间距与 boost。
