## P0-1：枝节疤黑色鼓包过大过死

**位置**: `drawBambooTwig` 函数

### 改动1：钉头起笔（约2458行）
| 参数 | 修复前 | 修复后 |
|------|--------|--------|
| 椭圆半径 | `baseW * 1.4` | `baseW * 0.6` |
| 椭圆尺寸比 | 1.1 × 0.72 | 1.0 × 0.68 |
| 墨色 | `INK.jiao`（焦墨/近死黑） | `INK.nong`（浓墨，有层次） |
| alpha | `0.95` | `0.60` |
| 第二颗挫笔半径 | `nailR*0.55`（=baseW*0.77） | `nailR*0.25`（=baseW*0.15） |
| 第二颗挫笔alpha | `0.70` | `0.30` |
| 第二颗偏移 | `nailR*0.3` | `nailR*0.25` |

效果：钉头直径从竿径的 ~2.8倍（1.4×2）降到 ~1.2倍（0.6×2），墨色从死黑变为浓墨半透明，不再像螺丝帽/瘤子。

### 改动2：节墨点（约2500行）
| 参数 | 修复前 | 修复后 |
|------|--------|--------|
| 圆点半径 | `baseW * 0.35 + 0.5` | `baseW * 0.15 + 0.3` |

### 钉头位置说明
钉头始终画在 `dpts[0]`（枝的着竿处），不会在枝中段出现。枝中段的黑色节点来自"节墨点"循环（已缩小降概率），不是钉头重复。

## P0-2：锥度不足

**位置**: `drawBambooStalk` 函数 `widthAt`（约2527行）

### 改动：线性锥度 → 三段非线性锥度

**修复前**:
```js
const taper = 1.0 - 0.75 * t;  // 线性，t=0.5时还是0.625
```

**修复后**:
```js
let taper;
if (t < 0.50) {
  taper = 1.0 - 0.90 * t;                       // 1.0 → 0.55（光竿段即明显收分）
} else if (t < 0.85) {
  taper = 0.55 - 0.71 * ((t - 0.50) / 0.35);    // 0.55 → 0.30
} else {
  taper = 0.30 * Math.pow(1 - (t - 0.85) / 0.15, 1.5); // 0.30 → 0（梢端收杀）
}
```

### local 肉感函数微调
避免中段 local 反向膨胀抵消锥度：
- t=0.05-0.50: 从 1.0 降到 0.96（原降到0.95）
- t=0.50-0.85: 从 0.96 降到 0.88（原0.95→0.85）
- t>0.85: 0.88 线性降到0（原0.85幂1.2）

### 锥度比值
- 根(t=0): taper=1.0, local≈0.92, 宽度 ≈ 0.92 pw0
- t=0.5: taper=0.55, local≈0.96, 宽度 ≈ 0.53 pw0
- t=0.85: taper=0.30, local≈0.88, 宽度 ≈ 0.26 pw0
- 梢(t=1): taper≈0, 宽度 ≈ 0（clamp到0.06 pw0）
- 根:梢 ≈ 0.92:0.06 ≈ 15:1（数学值），视觉因飞白/铺贴约6-8:1

### 节环可见性验证
节环用 `widthAt(tpos)*0.20` 作线宽，`Math.max(2.0, ...)` 兜底。
- t=0.5 时 nodeW≈0.53 pw0，主竿pw0≈14 → nodeW≈7.4，lineWidth≈2.0（兜底值）
- t=0.9 时 taper≈0.19，nodeW≈2.5，lineWidth≈2.0
- 全高度节环均可见，P1成果未破坏。

## P0-3：三竹剪影"棒棒糖"

**位置**: `buildBamboo` 出枝循环（约1450行起）

### 改动1：出枝阈值降低
```js
// 修复前
const branchStartT = 0.40 + rand(s*60) * 0.10;  // 0.40-0.50
// 修复后
const branchStartT = 0.38 + rand(s*60) * 0.08;  // 0.38-0.46
```
光竿比例从 ~55-60% 降到 ~38-46%。

### 改动2：中部长枝加长
```js
// 修复前: bLen = 120 + rand*60;  // 120-180
// 修复后: bLen = 140 + rand*40;  // 140-180（下限提高20px）
```

### 改动3：矮竿中部长枝绝对值下限
```js
// 新增：非主竿且 nodeT<0.55 的枝，缩放后不足100px则补到100-120px
if (!isMain && nodeT < 0.55 && bLen < 100) bLen = 100 + rand(s*82+ni)*20;
```
解决右竿（scale最小、hMulOpt=0.62）最长枝仅60px的问题。compose模式下 Lmul*0.55≈1.02，×0.85≈0.87，140*0.87≈122px（已>100），但上限180*0.87≈157，部分短随机会落到<100，此clamp保底。

### 改动4：长枝中段雀爪（新增）
在主枝 push 后、末端雀爪之后，新增中段雀爪生成：
- 触发条件：`bLen > 120` 且 60% 概率
- 位置：枝长 40-60% 处（`midT = 0.40 + rand*0.20`）
- 数量：2根细枝（比末端雀爪的2-3根少）
- 长度：8-15px（比末端雀爪的15-30px更短更细）
- width: `twigW*0.45`，depth=4（淡墨新枝）
- 每根雀爪端有小叶簇（'sub'类型）

目的：打破长枝中段100px完全空白的光弧，让华盖横向展开处有呼吸细节。

### 改动5：连续同侧出枝概率降低
```js
// 修复前: rand < 0.20  → 20%连续同侧
// 修复后: rand < 0.10  → 10%连续同侧
```
减少中竿连续同侧出枝的机械感。

## P1 检查：老枝/新枝墨色分级

**结论**: depth 赋值正确，墨色分级实际已生效，无需修改。

### depth 赋值（buildBamboo）
| 枝位置 | depth | twigW（主竿） | 判定 |
|--------|-------|--------------|------|
| nodeT < 0.60（中部长枝） | 2 | 7.0 | isOld=true → 焦墨INK.jiao + stamp/stampDry |
| 0.60 ≤ nodeT < 0.80 | 3 | 4.5 | isMid=true → 浓墨INK.nong + stampNong/stampNongDry |
| nodeT ≥ 0.80（梢部） | 4 | 2.6 | else → 淡墨INK.zhong + stampZhong/stampZhongDry |
| 末端雀爪 | 3 | twigW*0.55 | 浓墨 |
| 中段雀爪（新增） | 4 | twigW*0.45 | 淡墨 |

### 渲染侧（drawBambooTwig）
- `isOld = b.depth <= 2` → twigColor=INK.jiao, alpha=0.92, brushPathFeibai（顿挫飞白）
- `isMid = b.depth === 3` → twigColor=INK.nong, alpha=0.84, brushPath
- else → twigColor=INK.zhong, alpha=0.76, brushPath

stamp 选择（704-711行定义，2478-2480行选择）三级齐全，墨色分级链路完整。
