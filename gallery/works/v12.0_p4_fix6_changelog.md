## 1. hScale 双重缩减 bug 修复

### 原问题

compose 模式下，三竿高度已经由 `composeLayout` 中的 `hMul` 控制：

- main：`1.25 - 1.40`
- sub：`0.70 - 0.85`
- far：`0.55 - 0.70`

但原代码又对非主竹应用：

```js
const hScale = isMain ? 1.0 : (0.60 + rand(s*17)*0.15);
```

随后：

```js
const totalH = H * hScale * (0.95 + rand(s*19)*0.1) * curHMul;
```

因此辅竹/远竹在 compose 模式下被 `curHMul` 和 `hScale` 两次缩减，辅竹实际高度明显偏低。

### 修复后

```js
const hScale = (composeLayout && composeLayout[s])
  ? 1.0
  : (isMain ? 1.0 : (0.60 + rand(s*17)*0.15));
```

效果：compose 三竹布局中仅由 `curHMul` 控制高度比例；非 compose/单株旧路径仍保留原来的 `hScale` 行为。

## 2. 骨架预检模式 ?skeleton=1

启用方式：

```text
ink-garden.html?compose=1&gallery=1&skeleton=1
```

实现位置：

- URL 参数检测：IIFE 变量声明区
- 渲染函数：`renderSkeleton()`
- 渲染入口：主 `loop()` 内纸底绘制后、山水/植物水墨绘制前短路返回

骨架模式仍正常执行 composeLayout 和枝/叶几何计算，只替换最终水墨渲染。

### 视觉规则

- 主竹：`rgba(220,60,60,0.8)`，竿线宽 2
- 辅竹：`rgba(60,120,220,0.8)`，竿线宽 2
- 远竹：`rgba(60,180,60,0.8)`，竿线宽 2
- 枝条：同竿角色色，alpha 0.4，线宽 1
- 叶簇 bbox：同竿角色色，填充 alpha 0.12，描边 alpha 0.5
- 竿基部：半径 4px 实心圆
- 左上角 overlay：半透明白底、黑色 monospace 指标

### Overlay 指标

- Canvas W/H
- 各竿 role/baseX/topX/H/angle(度)/hMul
- span（竹丛跨度 px）
- rightBlank（右留白比例 %）
- 三竿 baseX 间距及 CV%
- 三竿高度比：sub/main、far/main

说明：overlay 中的 angle 采用 canvas 数学角（水平向右为 0°，向上约 -90°）。右欹主竹通常在 -80° 左右，左欹辅竹通常在 -100° 左右。
