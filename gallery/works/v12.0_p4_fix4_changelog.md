# v12.0 P4-fix4 Changelog

日期：2026-08-15
目标：修复 P4 构图三个核心问题——枝叶零交错、欹势不够、整体偏左。仅做参数调整，不改逻辑。

## 备份

- `ink-garden.html.bak-p4-fix3`（P4-fix3 原文，183,343 字节）

## 修改清单（仅 8 处行级改动）

### 1. 整体竹丛右移 + 缩小间距促成交错（composeLayout）

| 参数 | P4-fix3 | P4-fix4 | 作用 |
|------|---------|---------|------|
| `mainDX` | `20 + _lr()*80`（20–100） | `120 + _lr()*80`（120–200） | 竹丛整体右移约 100px |
| `gap1` | `180 + _lr()*120`（180–300） | `130 + _lr()*90`（130–220） | 缩小主辅距，促枝叶交错 |
| `gap2` | `100 + _lr()*120`（100–220） | `90 + _lr()*90`（90–180） | 辅远紧密有层次 |
| `maxFarAbs` | `1200` | `1350` | 允许远竹稍右，填充右部 |

### 2. 欹势加强 + 竿身微弯方向与 lean 同向

- `leanAngleBoost` compose 分支：`0.40 → 0.55`。
  - 主竹：`0.22~0.37 × 0.55 ≈ 0.121~0.204 rad (6.9°–11.7°)`。
  - 辅竹：`-(0.18~0.33) × 0.55 ≈ -0.099~-0.182 rad (-5.7°~-10.4°)`。
- `bendDir`：compose 模式下从随机改为与 `lean` 同号——右欹主竹中腹右弯、左欹辅竹中腹左弯，不再随机抵消欹势；非 compose 路径保持原随机。

### 3. 主竹枝条大幅加长以制造交错

- 主竹 compose 枝长乘数：`Lmul * 0.75 → Lmul * 1.05`（+40%），辅竹仍为 0.55。
- 新增主竹中部长枝保底：
  ```js
  if (isMain && isCompose && nodeT < 0.65 && bLen < 120) bLen = 120 + rand(s*82+ni)*25;
  ```
  确保 compose 主竹中部长枝不短于 120px。

### 4. 主竹跳枝率归零（顶部以上全出枝）

- compose 主竹覆盖 skipRate：`0.05 → 0.0`（顶部 3 节原有硬保底保持不变）。华盖更浓密。

## 严格未动

- P1/P2/P3 形态参数：`halfWRatio`、`foldChance`、`_windDir`、`rightFactor`、`_veinAlpha`、`ctrlBase` 等均无回归。
- z-order 排序、opts 透传、`mainLean/subLean/farLean` 数值、`baseYOff`、叶/节/竿逻辑均未改。
