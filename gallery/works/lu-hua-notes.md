# 芦花 · lu-hua

> 系列第十二件 · 画房（水墨互动）
> 蒹葭苍苍，白露为霜。所谓伊人，在水一方。
> 开笔 2026-09-13，v0913 首版，待主人审。

---

## 一句话
轻点江滩，起一阵秋风；风像手一样拂过芦荡，芦花低头、白絮被撕散，飘满江天。风住，穗回。

## 场景
秋江滩涂，下半幅芦荡、上半幅留白天空。远岸两道淡墨洲渚，渚上芦簇。纸白底、竖诗、绒球印。

## 交互
- **轻点/触摸**：从落点起一阵风，波前沿 x 以固定速度传播（风有「从哪来到哪去」），茎秆在波前经过时受力弯腰，波后回正。
- **长按拖动**：留下一股持续风（drag），整片顺向伏着。
- **风载散絮**：风力过阈值，白絮从穗部中上部被「撕」出，初速向上、平流随风、正弦沉浮，能飘到江面高处的留白里；一阵风凑够 18（快）/26（真实）絮，《秦风·蒹葭》竖排淡入。
- **远鸟**：风大时一只雁形两笔偶尔顺风掠过（接吴镇《芦花寒雁图》的寒雁母题，极克制）。
- **风住回响**：风过、飞絮将尽，一声玉磬（A5 sine + 长混响），像秋空的余音。

## 物理 / 绘制要点
- **悬臂弯曲**：每株芦苇是弹簧摆（k=15~21 劲挺有节、damp=1.7~2.4），风力矩 ∝ 风速 × 株高柔度；茎用 8 段（近）/5 段积分，局部倾角 ∝ s^1.7（根刚梢柔）。
- **阵风 = 生命周期包络 × 行波波前**：env=sin(π·age)，prof=高斯波前，是「波」不是「全场同时弯」。
- **芦花穗**：暖影软团打底（让白绒在纸白上浮起来）+ 米白软团叠体积 + 破碎随机绒羽/飘丝。**关键教训：等距 herringbone 丝缕画出来是麦穗/冷杉球果，不是芦花；必须随机碎绒 + 穗部独立固定随机源（每株 mulberry32，避免每帧跳变闪烁）。**
- **基部长草**：每株芦苇不再挂对称双弧门拱（那是装饰图案）；改为独立的「簇生草须」系统——一丛 7~16 枝、整丛偏向同一侧、长短不一、顺风伏贴。
- **三景深**：近景（大穗可读、茎节点）/中景/远景（淡笔触、聚成芦簇而非均匀栅栏；基线抬到洲渚线）。
- 远洲渚上的远芦是 13 丛错落簇笔，不是等距刻度竖线。

## 参照系
吴镇《芦花寒雁图》：前景劲挺芦叶统一倾偃、水面大片留白；
边寿民芦雁册：芦穗蓬松、风势明确；
逆光芦花摄影：白色绒羽透光 + 基部暖棕脉络、集体同向弯腰。

## 音频（audio-lib v1）
- 风：棕噪积分 → bandpass(480/Q0.6) → lowpass(1400)，频率与增益跟全局风速；
- 散絮：白噪声 highpass(2600) 短促小爆发，速率跟 torn；
- 诗显：极轻钟声；风住：A5 玉磬 + 长混响。

## 验收（CDP harness，fast 钩子）
- 种子 7/42/123 快进：峰值穗弯 0.309 / 0.326 / 0.509 rad（18°/19°/29°，优雅弯腰不翻折）；
- 风住 2s 波全部清、gusts=0、theta 回到 0.05~0.07 rad；
- 真实节奏 8.5s：空中 180 朵飞絮、诗已显、回正 1.6°；
- m390 竖屏：竖诗 + 斜扫芦秆构图成立，无横向溢出；
- 三种子 pageerror 为空；
- 峰值帧给「不知道机制的人」看，读得出「一阵风把芦花吹散了」。

## 本轮调参记录（踩坑）
1. v1 力矩过大：峰值 1.83rad（105°，芦苇被吹翻）→ 收到 14.5，落在 18~29°；
2. 穗初版 alpha 太低像光杆林 → 暖影底 + 米白软团立体积；
3. 等距丝缕像麦穗 → 随机碎绒（核心材质修正）；
4. 基叶对称门拱很假 → 独立簇生草系统；
5. Python 批量替换误改箭头函数定义体（rand→prand 连锁），造成 pgtrand 未定义静默崩 IIFE；靠 `Page.addScriptToEvaluateOnNewDocument` 注入 onerror 才抓到（window.onerror 在导航前注入会丢）。
