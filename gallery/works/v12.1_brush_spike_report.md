# v12.1 笔触渲染 Spike 报告

**日期**：2026-08-15
**目标**：验证"单笔画出提按顿挫+飞白"在Canvas 2D技术可行
**结论**：✅ 方向走通，但仅验证到60%，参数和审美需大幅调校

---

## 一、采用方案

**离屏canvas多边形clip + 多层stamp铺贴 + destination-out飞白**

1. `createInkStamp`：逐像素生成带纤维条纹、干笔颗粒、不规则椭圆边缘的笔触印章
2. `_samplePathDense`：沿中心线按弧长1.2px密采样
3. 每点按"提按包络"（pressureFn）算宽度，左右边缘各自加：低频正弦波+高频随机锯齿+整体颤笔
4. 左右边缘点构成多边形 → clip
5. 多层stamp填充：layer0湿笔核心（spacing 1.8）、layer1干笔散锋（spacing 3.0，仅后半段）
6. `destination-out`刮丝状留白+点状颗粒 = 飞白
7. 贴回主canvas

新增函数：`createInkStamp`/`getInkStamp`/`_samplePathDense`/`brushStrokeV5`/`makeOrchidPressureV5`/`makeBambooLeafPressureV5`（约350行）。
兰叶、竹叶draw函数改写为调用brushStrokeV5。

**未采用的方向**：
- 纯`ctx.stroke()`+动态lineWidth：Canvas沿路径lineWidth变化支持差，无法做飞白
- SVG feTurbulence filter：headless Chrome兼容性/性能存疑，未实测
- WebGL shader：杀鸡用牛刀，Canvas方案已够

## 二、效果自评

| 对象 | "像毛笔写"评分 | 说明 |
|---|---|---|
| 兰叶 | 5.5/10 | 根部重、收笔尖的提按成立，但**叶子整体过粗过黑**，像粗铁棍而非兰叶；飞白在1x缩放下几乎不可见 |
| 竹叶 | 6/10 | 边缘锯齿破边明显改善，从光滑矢量披针形变成有毛糙感的墨迹；但叶形变钝，丢失了竹叶的尖锐爽利 |

整体从"等宽铁丝/矢量填色"进步到"有肌理的墨迹"，**数字感明显下降**。

## 三、仍然存在的问题（为什么还不是作品）

1. **兰叶maxW放大1.8倍过度**——钉头鼠尾包络让兰叶中后段过粗，传统兰叶应是细劲飘举，现在显得笨重。需要回调base宽度，让提按是"细微呼吸"而非"肿起来"。
2. **飞白在正常视距下不可见**——颗粒和丝白都做到像素级了，但1x下被stamp密度盖住。要么加大飞白刮除强度和宽度，要么接受"微距看才有"。
3. **竹兰墨色仍未区分**——两边都偏焦浓，远看融成一团，缺"竹刚兰柔"的墨阶对比。这不是笔触引擎能解决的，需要上层给兰分配更淡的墨色（清墨#9a8d76一档）。
4. **竹叶丢了尖锐感**——多边形clip+stamp边缘让叶尖变圆钝。竹叶要的是"疾风骤雨"的锐利出锋，需要包络在收笔处更激进地收窄。
5. **没有题款/印章/地子/构图经营**——这是"作品感"的最大缺口，纯技术层补不了。
6. **性能**——每笔创建离屏canvas，兰竹合景数十笔，需评估帧率（stamp已缓存但offscreen每帧新建）。

## 四、下一步建议（v12.1正式版路线）

- [ ] 兰叶base宽度回调，钉头幅度减小，恢复细劲
- [ ] 竹叶收笔包络加重出锋，保留锐利
- [ ] 飞白强度上调一档（streak width + erase alpha + 降低density阈值）
- [ ] 上层墨色分配：竹焦浓、兰淡清，拉开2个墨阶
- [ ] 竿身也迁移到brushStrokeV5（目前竿仍是旧stamp铺贴）
- [ ] 性能：offscreen canvas对象池复用
- [ ] 构图层：题款、闲章、根地苔点
- [ ] 改完重新出4 seed图走双轨评审
