## 立意
湖畔夜色，一盏未燃的天灯泊在岸口。点灯人写下心愿，灯暖了，随风而起；
灯到高处化作一颗星——下次回来，星还在。点星可见当时心愿，可收下整张星图卡片，
也可让「星落」清空重来。放满五盏，李白《行路难》自现：
「长风破浪会有时，直挂云帆济沧海」。
立意落在「灯灯相续」：愿望不是一次性的烟花，而是会留下、会被回访的记录。

## 形制
- 单文件 HTML 零依赖（51.8KB / 1534 行），Canvas 2D 全屏夜景，字体 Google Fonts 非阻塞加载
- 场景：夜空渐变 + 满月（月海斑点/光晕）+ 双层山脊剪影 + 湖面月路碎光 + 涟漪 + 岸线芦苇
- 天灯状态机：`ground`（未燃，月光勾边）→ `lighting`（1.4s 点亮，灯体四色渐变由夜褐转暖橙）
  → `rising`（加速上升 + 风摆 + 灯面竖排心愿题字前四字 + 火苗闪烁 + 水中倒影）
  → `star`（化为暖星，定格后 FIFO 淡出，天上同时挂 14 颗）
- 交互：短按地灯=单灯面板；长按 620ms=双灯齐放面板（同伴灯错峰点亮、并肩上升、共载同心愿）；
  点灯/点星=气泡显示心愿与日期；预设心愿 chips（毕业快乐/旅途平安/前程似锦/得偿所愿/平安喜乐）+ 自定义 12 字
- **跨访问星空（v2 存储）**：localStorage `tiandeng_sky_v1`，双轨——
  `stars`（天上还挂着的星，上限 60 FIFO）+ `wishes`（全部心愿记录，永不因淡出丢失）；
  重开页面历史星回挂（`Lantern.fromRecord` 位置/大小/心愿/日期固定只闪烁）
- **星图回放「我的星空」**：蛇形保序布局（越早的灯越高远，原 fx 方位做微扰锚定，任意数量都散开可辨），
  点星显心愿；「收下星图」导出 1080×800 PNG 卡片（落款 + 日期 + 绒球印）；
  「星落」清空走二次确认弹层（「这一页翻过去，就找不回来了」）
- 诗印：released≥5 时李白《行路难》双列竖排 4s 渐显 + 绒球朱印
- 声（Web Audio 全程序化）：棕噪风声（lowpass 380Hz + LFO 起伏）+ 蟋蟀（4100Hz triangle 随机啁啾）
  + 放灯五声音阶磬音（C/D/E/G/B sine+倍频，2.6s 衰减）
- 测试钩子：`?fast=1`（加速物理）`?auto=N`（自动放N盏）`?pair=1` `?presky=N`（预置历史星）
  `?warp=S`（快进秒数）`?nostore=1`（不落存储）`?seed=` `?panel=1`；隐藏 `#state` 400ms 镜像全状态

## CDP harness 避坑（本轮实锤，供复用）
1. 点击坐标必须取运行时真实位置（`ground.x/y + canvasRect`），`window.innerHeight` 视口 ≠ `--window-size`（headless 有滚动条/UI 差，实测 860 设定下画布 717）
2. 物理时序：正常速度灯升空 ≈16s，功能旅程用 `?fast=1`；断言用轮询 `waitFor(predicate)` 而非固定 sleep
3. 顶层 `let/const` 是词法全局不挂 `window`，evaluate 里直接用裸名，勿写 `window.xxx`
4. `Page.navigate` 后 Runtime context 复用不稳时，重新拉 target 建连最保险
5. 测试 profile 脏 localStorage 会污染「空初始」断言，每场景独立 `user-data-dir` 并清理
