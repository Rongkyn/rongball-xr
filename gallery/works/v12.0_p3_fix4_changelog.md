## Fix-A：收窄中脉留白，消除深叶"裂缝/胶带"感

**文件位置**：`drawBambooLeaves` 中脉 `destination-out` 块（约 2346–2366 行）

| 项 | fix3 | fix4 |
|---|---|---|
| globalAlpha（中/重叶） | `0.12 + rand*0.06`（0.12–0.18） | `0.05 + rand*0.05`（0.05–0.10） |
| 焦浓叶(nong) alpha 系数 | 无 | 再 ×0.7（0.035–0.070） |
| lineWidth | `Math.max(0.3, maxHalf*0.08)` | `Math.max(0.2, maxHalf*0.045)` |
| 脉线路径 | 笔直 `quadraticCurveTo(midx,midy,ex,ey)` | 控制点沿法线随机偏移 ±maxHalf×0.15，微有弧度 |
| 触发条件 | `len>40 && tone!=='dan' && tone!=='qing'` | **保留不变**（淡清叶不画中脉） |

**物理量验算**：
- 深叶(nong) 中脉 alpha = 0.05~0.10 × 0.7 = **0.035~0.070**（原 0.12~0.18，降幅约 60%）
- 中叶(zhong) 中脉 alpha = **0.05~0.10**（降幅约 50%）
- 线宽：maxHalf≈3-5px × 0.045 = 0.135–0.225px → 下限 0.2px（原 0.24–0.40px，收窄约 45%）
- 脉线弧度偏移量：±(maxHalf×0.15) ≈ ±0.45–0.75px，自然不机械

## Fix-B：统一风势，消除叶片朝向散乱

**文件位置**：`drawBambooLeaves`（约 1971、2050–2054 行）

| 项 | fix3 | fix4 |
|---|---|---|
| `_windDir` 初始化 | `0.35 + rand*0.10`（0.35–0.45 rad） | `0.45 + rand*0.10`（0.45–0.55 rad） |
| windBias 公式 | `_windDir × (0.6 + n×0.10 + rand×0.18)` | 80% 顺应 / 20% 逆势（见下） |
| 叶序索引项 n×0.10 | 有（越靠后偏角越大） | **删除** |
| angJitter | `(rand-0.5)×0.10`（±0.05 rad） | `(rand-0.5)×0.06`（±0.03 rad） |

新风势公式：
```js
const followWind = this.rand(b.id+n*77) >= 0.20;   // 80% 顺主势
const windSign   = followWind ? 1 : -1;             // 20% 逆势破局
const windStrength = followWind
  ? (0.7 + this.rand(b.id+n*41)*0.25)   // 顺风 0.70–0.95
  : (0.3 + this.rand(b.id+n*41)*0.30);  // 逆势 0.30–0.60（强度减半）
const windBias = this._windDir * windSign * windStrength;
```

**物理量验算**：
- 主势风向角 = 0.45–0.55 rad = **25.8–31.5°**（原 20.1–25.8°，主势更明确）
- 顺风叶 windBias = 0.45×0.70 ~ 0.55×0.95 = **+0.315~+0.523 rad（18–30°）**
- 逆势叶 windBias = −(0.45×0.30 ~ 0.55×0.60) = **−0.135~−0.330 rad（−8~−19°）**
- angJitter = ±0.03 rad = **±1.7°**（原 ±2.9°，散乱度降 40%）

## Fix-C：加密叶量 + 疏密极值，增强华盖感

**文件位置**：`buildBamboo` 雀爪块（约 1593、1600 行）、`_addBambooLeafCluster`（约 1662–1673 行）、`drawBambooLeaves` 字法数组（约 1983–2020 行）

### C1 雀爪概率
| 项 | fix3 | fix4 |
|---|---|---|
| 中部长枝雀爪触发率 | `rand < 0.60` | `rand < 0.78` |
| 雀爪双根(subN=2)概率 | `rand < 0.50` | `rand < 0.65` |

### C2 每簇叶数
| 字法 | fix3 | fix4 |
|---|---|---|
| 人(ren) | 固定 2 叶 | 2 叶为主，**30% 概率加 1 小附叶**（3 叶） |
| 个(ge) | 固定 3 叶 | 3 叶为主，**40% 概率加 1 侧叶**（4 叶） |
| 介(jie) 主枝长枝(bl>100) | 4–5 叶 | **4–6 叶** |
| 介(jie) 雀爪/其他 | 4 叶 | **4–5 叶** |

### C3 疏密极值（华盖聚集感）
在 `sizeMul` 上叠加 `_densityMul`：
- 竹冠顶部 `upFactor >= 0.7`：× **1.12**（叶簇放大 12%）
- 下部 `upFactor < 0.4`：× **0.85**（叶簇缩小 15%）
- 中部：× 1.0

### C4 配套：字法数组扩展（Fix-C 生效的必要条件）
原 `drawBambooLeaves` 中 `offs`/`mainFactors`/`tonePlan` 数组长度分别为 2/3/5，且 strokes 被 `Math.min(5, …)` 硬截断——导致 Fix-C 设的 lcMax=3/4/6 全部被截掉。为让"加一片小附叶"真正生效，同步扩展：
- 人(ren)：offs 2→3、mainFactors 2→3（新增 0.62 小附叶）、tonePlan 2→3（新增 'dan'）
- 个(ge)：offs 3→4、mainFactors 3→4（新增 0.66 侧叶）、tonePlan 3→4（新增 'dan'）
- 介(jie)：offs 5→6、mainFactors 5→6（新增 0.60 破笔）、tonePlan 5→6（新增 'dan'）
- strokes 全局上限 5→6；`isTop` leafCount 覆盖上限 5→6

新增附叶均为短(0.60–0.66)、淡墨(dan)，符合宋画"破笔/附叶"笔法，不抢主笔。
