## 2. 布局函数（内联在 buildBamboo 中）

位置：`buildBamboo()` 函数体，`branchSide` 之后、`stalkCount` 循环之前。
触发条件：`isCompose && stalkCount >= 3`。非 compose 或 stalkCount<3 路径完全保留旧逻辑。

```js
let composeLayout = null;
if (isCompose && stalkCount >= 3) {
  const _seedVal = (typeof opts.seed === 'number') ? (opts.seed | 0) : ((this.seed | 0) || 42);
  let _ls = _seedVal;
  const _lr = () => { _ls = (_ls * 1664525 + 1013904223) | 0; return ((_ls >>> 0) % 10000) / 10000; };

  // 主竹：x偏左1/3，hMul 1.25-1.40，右欹
  const mainDX = -30 + _lr() * 60;
  const mainHMul = 1.25 + _lr() * 0.15;
  const mainLean = 0.15 + _lr() * 0.15;
  const mainTilt = (_lr() - 0.5) * 0.02;

  // 辅竹：主竹右侧 150-330px（不等距），hMul 0.70-0.85，左欹（顾盼）
  const gap1 = 150 + _lr() * 180;
  const subDX = mainDX + gap1;
  const subHMul = 0.70 + _lr() * 0.15;
  const subLean = -(0.10 + _lr() * 0.15);
  const subTilt = (_lr() - 0.5) * 0.02;

  // 远竹：辅竹右侧 280-450px，hMul 0.50-0.65，随风同向；baseYOff 150-250（藏露）
  const gap2 = 280 + _lr() * 170;
  let farDX = subDX + gap2;
  const farHMul = 0.50 + _lr() * 0.15;
  const farLean = 0.10 + _lr() * 0.10;
  const farTilt = (_lr() - 0.5) * 0.02;

  // 留白保护：this.x(≈420) + farDX < 1250
  const maxFarAbs = 1250;
  if (this.x + farDX > maxFarAbs) farDX = maxFarAbs - this.x - 10;

  composeLayout = [
    { dx: mainDX, hMul: mainHMul, lean: mainLean, tilt: mainTilt, role: 'main', baseYOff: 0 },
    { dx: subDX,  hMul: subHMul,  lean: subLean,  tilt: subTilt,  role: 'sub',  baseYOff: 0 },
    { dx: farDX,  hMul: farHMul,  lean: farLean,  tilt: farTilt,  role: 'far',  baseYOff: 150 + _lr() * 100 }
  ];
  // 调试钩子
  if (typeof window !== 'undefined') {
    window._lastComposeLayout = composeLayout.map(c => ({ dx:c.dx, x:undefined, hMul:c.hMul, lean:c.lean, tilt:c.tilt, role:c.role, baseYOff:c.baseYOff }));
  }
}
```

LCG 采用 Numerical Recipes 常数（1664525 / 1013904223），与 `this.seed` 完全独立，确保构图参数不受其他 rand 调用污染，可重现。

**最终 gap 范围**：gap1 ∈ [150, 330]，gap2 ∈ [280, 450]，仿真 3000 seed 下：
- CV mean = 0.213，CV > 20% 占 52%，CV > 15% 占 67%
- 15 seed 实测 CV mean = 21.6%，全部满足顾盼 / farX<1250 / 高度差>15%

## 3. 循环改造（stalkCount loop）

将原本硬编码的 `isMain / hMulOpt / off / lean / tilt` 全部走 `cur*` 变量，
非 compose 路径从默认值初始化，compose 路径用 `composeLayout[s]` 覆盖：

| 变量 | 非 compose 默认 | compose 覆盖（外部 opts 优先） |
|------|-----------------|---------------------------------|
| `isMain` | `s === 0` | `cl.role === 'main'` |
| `curHMul` | `opts.heightMul ?? 1` | `opts.heightMul ?? cl.hMul` |
| `curLean` | 旧 lean 逻辑 | `opts.lean ?? cl.lean` |
| `curTilt` | 旧 tilt 公式 | `cl.tilt` |
| `curOff`（=x 偏移） | 旧 off 公式 | `cl.dx`（=layout.dx） |
| `curBaseYOff`（=y 下移） | 0 | `cl.baseYOff`（远竹 150-250） |
| `curRole` | null | `'main' / 'sub' / 'far'` |

竿身粗细分档（保持 P3 v11.0 分档结构，远竹额外 ×0.8）：
- `curRole==='far' || curHMul<0.70` → wScaleByH = 0.62
- `curHMul>=1.05` → 1.18（主）
- `curHMul>=0.85` → 0.92（辅）
- 其余 → 0.78

`_stalkBaseY = this.y + curBaseYOff`：远竹起点 y 下移 150-250px，竿身在画布外、只露梢顶约 1/3。

每个 branch / twig / 叶簇对象都打标 `_composeRole: curRole`（stalk 主枝、主枝 twig、雀爪 twig、雀爪叶簇、主枝端叶簇、梢头小叶共 6 处 push 点；`_addBambooLeafCluster` 增加第 14 参 `composeRole`）。

调试钩子：每个 stalk 构建结束后把 x / hMul / lean / baseYOff 回填到 `window._lastComposeLayout[s]`，供多 seed 自动验证读取。

## 4. z-order 藏露（draw 方法）

在 `draw()` 循环前对 branch 列表做**一次性稳定排序**，仅当列表中存在 `_composeRole` 时才排：

```js
const roleRank = { 'far': 0, 'sub': 1, 'main': 2 };
orderedBranches = this.branches.slice().sort((a,b) => {
  const ra = a._composeRole != null ? roleRank[a._composeRole] : 1;
  const rb = b._composeRole != null ? roleRank[b._composeRole] : 1;
  if (ra !== rb) return ra - rb;
  return (a.id||0) - (b.id||0);   // 同 role 内保持原 id 序
});
```

绘制顺序：**远竹 → 辅竹 → 主竹**，主竹枝叶覆盖在最前，形成藏露。
非 compose 模式下 `orderedBranches === this.branches`（同一引用），零开销、零行为变化。
