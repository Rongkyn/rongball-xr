## Fix-1：ctrlOffset 运算符优先级 bug（🔴 最关键）

**文件位置**：原约 2077 行 → 修复后拆分为 2107–2111 行。

**Before（P3-fix1）**：
```js
const ctrlOffset = (n === 0 ? 0.14 : 0.16) + (n >= 3 ? 0.02 : 0) * len;
```
由于 `*` 优先于 `+`，实际值 = `0.14 + (0 或 0.02*len)`，主笔只有 ≈0.14 px 偏移（而非 len 的 14%），C 形弧弯几乎不生效。

**After（P3-fix2）**：
```js
const ctrlBase = ((n === 0 ? 0.14 : 0.16) + (n >= 3 ? 0.02 : 0)) * len;
if (curveType === 'straight') {
  ctrlOffset = ctrlBase * 0.3;
} else {
  ctrlOffset = ctrlBase;
}
```
主笔 ctrlOffset = 0.14 × len ≈ 8.4 px（len=60），外层 0.18 × len ≈ 12.6 px，C 形弧弯真正生效。`straight` 类型使用 30% 偏移以保留极微弧度。

## Fix-2：叶尖放缓，消除飞镖感

**文件位置**：`hwAt(t)` 函数，原约 2108–2114 行 → 修复后 2138–2148 行。

**Before**：
```js
if (t < 0.82) return maxHalf * (1.0 - 0.55*((t-0.30)/0.52));
const k = 1 - (t-0.82)/0.18;
return maxHalf * 0.45 * Math.pow(Math.max(0, k), 0.35);
```
中段收到 0.45，末段 pow 0.35 太急——视觉上像飞镖 / 针。

**After**：
```js
if (t < 0.82) return maxHalf * (1.0 - 0.50*((t-0.30)/0.52));
const k = 1 - (t-0.82)/0.18;
return maxHalf * 0.50 * Math.pow(Math.max(0, k), 0.50);
```
- 中段终点：t=0.82 处 hw 从 0.45 → **0.50**（略宽，避免中段过窄后急收）。
- 末段幂指数：pow(k, 0.35) → **pow(k, 0.50)**（收束更自然但仍有锋）。
- 末段起始 hw：0.45 → **0.50**，与中段平滑衔接。

叶基（t<0.06）和最宽段（t≈0.30）保持不变。

## Fix-3：折叶加强

**文件位置**：
- `foldChance`：原 2008 行 → 2008 行。
- `drawOpacity / backOpacity`：原 2033–2039 行 → 2033–2041 行。
- 后半段填充 alpha：约 2253 行（新增 `ctx.globalAlpha = aBack`）。
- 折痕 alpha：原约 2278 行 → 2289 行。

**改动**：

| 项 | Before | After |
|---|---|---|
| `foldChance` | `0.12` | **`0.16`**（约 16% 叶片折叶） |
| 折叶前半段 drawOpacity | `0.70` | **`baseOpacity`**（保持原 tonePlan 的 nong/zhong opacity 不变，前浓） |
| 折叶后半段 opacity（新增独立 `backOpacity`） | 与前半共用 0.70 | **`0.80`**（前浓后淡反差加大） |

**实现要点**：

- 非折叶路径中 `backOpacity = baseOpacity`，`aBack = a`，行为不变。

## Fix-4：弧弯多样化（打破同质化）

**文件位置**：原 2071–2077 行（curve/curveBase/curveOuter/ctrlOffset）→ 修复后 2071–2112 行。中心线贝塞尔控制点采样位置：原 2126–2127 行 → 修复后 2162–2163 行。

**Before**：所有叶子同向 C 形弧弯：
```js
const curve = (curveBase + curveOuter) * sideSign;
const aEnd = na + curve;
// 控制点：
const mx = sx + (ex-sx)*0.45 + Math.cos(ang+Math.PI/2*sideSign)*ctrlOffset;
```

**After**：引入 4 种 curveType（基于 `this.rand(b.id + n*77)` 一次性判定）：

```js
const curveRand = this.rand(b.id + n*77);
let curveType, curve, ctrlOffset, ctrlSign;
if (curveRand < 0.60) {
  curveType = 'C';                                    // 60%
  curve = curveFull * sideSign;
  ctrlSign = sideSign;
} else if (curveRand < 0.75) {
  curveType = 'straight';                              // 15%
  curve = (0.02 + this.rand(b.id+n*79)*0.03) * sideSign;
  ctrlSign = sideSign;
} else if (curveRand < 0.90) {
  curveType = 'S';                                     // 15%
  curve = curveFull * 0.5 * sideSign;                 // 弯度减半
  ctrlSign = sideSign;
} else {
  curveType = 'reverse';                               // 10%
  curve = -curveFull * sideSign;                      // 方向与 sideSign 相反
  ctrlSign = -sideSign;                               // 控制点方向也反
}
let aEnd = na + curve;
if (curveType === 'S') {
  aEnd = na - curve * 0.3;                            // 末端反向 30%，形成 S
}
```

**贝塞尔控制点采样同步改用 `ctrlSign`**：
```js
const mx = sx + (ex-sx)*0.45 + Math.cos(ang+Math.PI/2*ctrlSign)*ctrlOffset;
const my = sy + (ey-sy)*0.45 + Math.sin(ang+Math.PI/2*ctrlSign)*ctrlOffset;
```

**各类型行为**：
- **C 形（60%）**：与 P3-fix1 行为一致，但因 Fix-1 修正了 ctrlOffset，弧弯真实可见。
- **straight（15%）**：curve 仅 0.02–0.05 弧度（约 1–3°），ctrlOffset × 0.3，近乎直叶但仍留笔意。
- **S 形（15%）**：弯度减半（curve × 0.5），但末端方向 `aEnd = na - curve*0.3`——前 2/3 沿 ctrlSign 正弯，后 1/3 回正形成 S。
- **reverse（10%）**：curve 与 sideSign 反向、ctrlSign = -sideSign，叶子反折，形成顾盼。

判定种子 `b.id + n*77` 与已有的 `b.id+n*31`（折叶）、`b.id+n*33`（curveOuter）等独立，避免相关性。
