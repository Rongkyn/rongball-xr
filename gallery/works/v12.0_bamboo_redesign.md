# 墨竹 v12.0 形态重构设计书

> 核心教训：v5.7–v11.2 共 30+ 个版本全部在"渲染层"打转（笔触、墨色、飞白、stamp 参数），
> 但 `buildBamboo` 生成的**植物学骨架本身就不是竹子**。无论渲染多精致，形态错了就永远不像竹。
> v12.0 从**形态生成层**推倒重来，渲染层（brushPath 双 pass 等 v11.2 成果）保留并适配。

---

## 一、当前 buildBamboo 的根本问题（诊断）

| # | 问题 | 现状代码 | 真实竹子 / 宋画 |
|---|------|----------|-----------------|
| 1 | **底部出枝** | `firstNode=0`，第一节就出枝，根部还有2簇贴根叶 | 竹子下部 1/3–1/2 是"亮竿"，光竿无叶无枝，枝只从上半部节上生 |
| 2 | **每节出枝** | 几乎每节都出枝（skip率仅12-20%），还加贴竿短枝/30%中叶/75%中叶/18%中叶/底部双枝/雀爪 | 真实竹子每节出 1-2 枝，但宋画只画可见的 5-8 枝，大量"省略" |
| 3 | **叶覆盖全竿** | 沿整根竿从底到梢都有叶簇（根部2簇、下部贴竿短枝叶、中下部30%中叶、雀爪叶、主枝叶、梢头叶） | 叶子只集中在**顶部 1/3 竹冠**，形成"修长光竿 + 顶部华盖" |
| 4 | **叶簇过度重叠** | 每个出枝节点平均产生 4-6 个叶簇（主枝端+雀爪1-2+短枝+30%中叶+75%中叶+18%中叶），全竿上千叶 | 宋画每竿总叶数控制在 30-60 片，**以少胜多** |
| 5 | **节间距均匀** | weights 按 t 线性递减（1.80→0.20），中段最长，底部和顶部均匀缩短 | 真实竹子：**基短→中长→梢短**，中部节间距最长（可接近竿宽10倍），根部和梢部明显缩短 |
| 6 | **竹节被埋** | 节环渲染逻辑存在，但被双 pass stamp 铺贴完全覆盖，视觉上看不见 | 宋画竹节是**最重要的身份特征**——竿上两道墨环（"鹊爪"），必须清晰可见 |
| 7 | **三竹篱笆** | compose 模式 x=420/820/1180 等距，等高（hMul 1.15/0.78/0.62 差异不足） | 宋画多竹：**主次分明**，主竹顶天立地，辅竹半藏，远竹只露梢；有藏露、穿插、顾盼 |
| 8 | **剪影纺锤** | 全竿均匀出枝叶 → 外轮廓中间宽两头窄，像狗尾草/鱼骨 | 竹子剪影：**下部细长（光竿）+ 顶部展开（竹冠）**，像火炬/华盖 |

## 二、竹子的真实生长结构（研究结论）

### 2.1 竹竿（culm/stalk）
- **圆柱形**，从根到梢逐渐变细（锥度明显）
- **节（node）**：环状突起，是竹子最标志性的特征；节间（internode）是两段节之间的空腔
- **节间距规律**：基部 2-3 节最短（甚至几乎贴地），中部节间距最长（可达竿径的 8-12 倍），上部又逐渐缩短
- **整竿约 12-18 个节间**（视高度），但画中通常只清晰画 8-12 个
- 竿身基本**笔直**，梢端微微弯曲（"点头"），整体可有轻微欹侧但不做大幅 S 弯

### 2.2 枝条（branch）
- **只从节上生出**，每个节上生 1-2 枝
- **下部节不生枝**（竹子生理：下部节的芽休眠），通常从**整竿 40%-50% 以上**的节才开始生枝
- 枝从节上**斜向上**生出（与竿夹角约 30°-60°），然后向外弧曲展开，梢端因叶重微微下垂
- 主枝较长（特别是中部几枝），越往上枝越短，梢部的枝最短（形成顶冠收束）
- 每根主枝上有**小枝（twig）**，小枝才承叶；小枝从主枝节上互生
- 宋画常画"雀爪"——主枝端部分叉成 2-3 根细枝，像雀鸟踩枝的爪

### 2.3 叶（leaf）
- 竹叶是**长披针形**，长 5-15cm，宽 1-3cm，先端渐尖（像剑尖），基部圆钝
- 每片叶有明显的**叶柄（pseudopetiole）**连接小枝
- **叶序**：小枝上的叶互生，但视觉上常形成**"个"字（3叶）、"人"字（2叶）、"介"字（4-5叶）**的簇状组合
- 叶子只长在**小枝末端**，不长在主枝或竿上
- 叶簇朝向随小枝方向展开，有**风叶（被风吹向一侧）、晴叶（自然舒展）、雨叶（下垂）**等姿态
- 一片小枝通常有 3-7 片叶，一整棵竹子画中通常 30-60 片叶

### 2.4 整体形态
- **整株剪影**：修长竿身（下部 1/2-2/3 裸露）+ 顶部竹冠（枝叶展开），像火炬/华盖
- **多株构图**：主竹最高最大，辅竹略短略细可被主竹部分遮挡，远竹细而淡只露梢顶；三竹不等距、不等高、有穿插

## 三、v12.0 重构方案

### 3.1 竿（Stalk）重写

#### 3.1.1 节间距（核心）
```
节间距模型：base短 → middle长 → top短
参数：
  - totalNodes = 12-16（主竿），8-10（辅/远）
  - 节间长度函数 internodeLength(i, n):
      t = i/(n-1)
      if t < 0.15:  L = minLen * (0.3 + t/0.15 * 0.7)       // 基部短节，渐长
      else if t < 0.55: L = minLen + (maxLen-minLen) * sin(((t-0.15)/0.40)*PI)  // 中部最长（正弦曲线）
      else: L = maxLen * (1 - ((t-0.55)/0.45)*0.7)          // 梢部渐短
  - minLen ≈ 竿宽 * 2-3
  - maxLen ≈ 竿宽 * 8-12
  - 加 ±10% 随机扰动
```

#### 3.1.2 锥度（taper）
- 竿宽从 baseW 线性收窄到 tipW = baseW * 0.25（不是当前的 widthAt 包络）
- 节部略宽（节环突起）：节处宽度 = 相邻节间宽度 * 1.08

#### 3.1.3 节环渲染（node ring）—— 必须清晰可见
- 在 brushPath 铺贴**之后**绘制，不被覆盖
- 每节两道墨痕：
  1. **下环（承上）**：一道短弧横线，略向上弯，墨色浓，线宽 = 竿宽 * 0.18
  2. **上环（启下）**：一道更短的弧，略向下弯，墨色稍淡，线宽 = 竿宽 * 0.12
  3. 两侧可有"鹊爪"短线（2-4 条，从节环向斜下方伸出，像枝痕/根须痕）
- 节环墨色比竿身深 1-2 档（用焦墨/浓墨），确保在 brushPath 铺贴之上清晰可辨
- 节环不使用 destination-out（那会擦掉竿身铺贴），直接用 source-over 深墨画

#### 3.1.4 竿身姿态
- 基本笔直，整体可有 2°-5° 微欹
- 梢端最后 2-3 节可有轻微"点头"弯曲（向 lean 方向偏 5°-15°）
- **禁止** S 弯、大幅曲线、波浪形

### 3.2 枝（Branch/Twig）重写

#### 3.2.1 出枝位置（核心改变）
```
branchStartT = 0.40 + rand()*0.10   // 从 40%-50% 高度才开始出枝，以下全是光竿
branchableNodes = nodes.filter((n,i) => t_i >= branchStartT)
```
- **下部 40%-50% 完全无枝无叶**——这是"亮竿"
- 从 branchStartT 到竿顶，每个节可出枝，但：
  - skipRate = 0.35（35%的节跳过不画枝，宋画以省略为美）
  - 每个节最多出 1 根主枝（不是当前的交替双出）
  - 枝的左右方向交替，但有随机（20%概率连续同侧，破机械感）

#### 3.2.2 枝的长度梯度
```
枝长 = f(t):
  if t < 0.55:  bLen = 120-180px（中部长枝，主承载叶冠）
  if t 0.55-0.75: bLen = 80-130px
  if t > 0.75: bLen = 30-60px（顶部短枝，收束冠形）
```
- 中部长枝是叶冠的主要骨架，向外展开形成冠幅
- 顶部短枝使竹冠收束，不形成平顶

#### 3.2.3 枝的弧度
- 从节上斜向上生出（与竿夹角 35°-55°），前 1/3 保持向上
- 中 1/3 弧向外展开（角度逐渐增加到 60°-80°）
- 末 1/3 因叶重微微下垂（角度增加到 80°-100°，梢端可略低于水平）
- 用 6-8 段 Catmull-Rom 或贝塞尔曲线画

#### 3.2.4 雀爪（小枝分叉）
- 仅在**中部长枝的末端 60%-80% 处**生雀爪
- 每根主枝 0-1 组雀爪（40%概率有）
- 雀爪 = 2-3 根细枝，从主枝分出，每根长 15-30px，端承叶簇
- 不是每根枝都有雀爪

#### 3.2.5 枝的渲染
- 主枝用 brushPath（浓墨/重墨），有钉头（起笔粗圆）鼠尾（收笔尖细）
- 细枝/雀爪用细 stroke 或细 brushPath（淡墨）
- 老枝（下部 t<0.6）墨色焦浓，新枝（上部）墨色清淡

### 3.3 叶（Leaf）重写

#### 3.3.1 叶片形态
- **长披针形**：长度 40-70px（compose），宽度 = 长度 * 0.12-0.18
- 叶尖：渐尖，最后 15% 急收为锋线（不是 arc 圆点——已知陷阱）
- 叶基：圆钝，有 3-5px 的叶柄连接小枝
- 叶片有**中脉**（一道淡墨细线，从柄到尖），但仅在大叶/前景叶画
- **C 形弧弯**：叶片整体可有 5°-20° 的弧形弯曲（单方向，不是 S 弯——已知陷阱），弯曲度随 ageFactor 增加（外层/老叶更弯）
- 折叶：10%-15% 的叶片有翻转（正面/背面），背面用淡墨

#### 3.3.2 叶组字法（核心）
- 每个叶簇 = 一个"字"：
  - **"人"字**（2叶）：两片叶从同一点向左右展开，夹角 40°-70°，一长一短
  - **"个"字**（3叶）：三片叶——一片向上（最长），一片向左下，一片向右下，像"个"字
  - **"介"字**（4-5叶）：在"个"字基础上加 1-2 片侧叶/小叶
- 每个小枝末端生 1 个字（2-5 片叶）
- 字的选择随机，但有比例："人" 30%、"个" 50%、"介" 20%
- 叶簇之间有间距（不是当前的叶簇叠叶簇），沿小枝排列，间距 15-30px

#### 3.3.3 叶的墨色
- 前景/主枝叶：浓墨（#2e2820），部分焦墨尖
- 中景叶：重墨（#443a30）
- 远景/背面/折叶：淡墨（#6b5e4c）
- 清墨（#9a8d76）仅用于最远/最小的叶，且占比 ≤10%
- **禁止**鲜绿、平涂（所有叶都有浓淡渐变）、鬼影（淡墨浅褐在暖宣低对比——已知陷阱）

#### 3.3.4 叶的渲染方式
- **v12.0 先用 v9.9 fillPath+渐变 画叶形**（已验证能出体量），但：
  - 加长叶片至 40-70px（当前太短）
  - 加宽到长度的 0.12-0.18
  - 加 C 形弧弯
  - 加字法排列
- brushPath 笔触化叶片留待 v12.1（v12.0 先把形态搞对）

#### 3.3.5 叶量控制（ROI关键）
- 每竿总叶数：
  - 主竿：40-60 片（8-12 个出枝节 × 每枝 1 主叶簇 3-5 叶 + 雀爪 1-2 簇 × 2-3 叶）
  - 辅竿：25-40 片
  - 远竿：10-20 片
- **远少于当前版本**（当前估计每竿 200+ 片）

### 3.4 构图（Composition）重写

#### 3.4.1 三竹配置（compose 模式）
```
主竹：x 偏左 1/3（约 350-450），hMul 1.2-1.4，最粗，顶天立地
辅竹：x 在主竹右侧 200-300px 处，hMul 0.7-0.85，中等粗，部分被主竹枝叶遮挡
远竹：x 再右 250-350px，hMul 0.5-0.65，最细最淡，只露梢顶或半竿
```
- **不等距**：间距 200-350px 随机，不是 400/360
- **不等高**：主竹最高（占画面 80%-90%），辅竹 60%-70%，远竹 40%-55%
- **藏露**：辅竹的竿身可被主竹的叶簇部分遮挡；远竹可只画梢顶 1/3，下部出画
- **顾盼**：主竹微向右欹，辅竹微向左欹（两竹相向有呼应），远竹随风同向

#### 3.4.2 留白
- 画面右侧 1/3 大面积留白（竹冠不填满）
- 竹竿下部 40% 全是光竿+宣纸留白
- 叶簇之间有透光间隙（不是黑块）
- 留白是"布白"——有形状的留白，不是空无一物

## 四、渲染层保留（v11.2 成果）

以下 v11.2 的渲染改进**保留不动**：
- `brushPath` 随机铺贴（jitter/尺寸随机/不透明度随机/相位偏移）
- 竿身双 pass（湿笔骨架 + 干笔颗粒）
- 竿身专用 stamp（stalkStamp/stalkStampNong/stalkStampZhong + Dry 变体）
- destination-out 飞白刮丝
- 三段墨色架构（焦→浓→重）

**需要调整的**：
- 节环渲染必须移到 brushPath 铺贴**之后**，用 source-over 深墨画，确保不被覆盖
- brushPath 的 spacing/dryness 等参数可能需要因新的竿宽锥度而微调
- 叶片参数需要适配新的长披针形

## 五、验收标准（v12.0）

### 5.1 硬门槛（必须全部通过才能进 Checker）
1. **一眼看出是竹**：竿有清晰节环、下部光竿、顶部叶冠
2. **剪影正确**：外轮廓是"修长光竿 + 顶部华盖"，不是纺锤/狗尾草
3. **节环可见**：每竿至少 6 个节环肉眼可辨（两道墨痕）
4. **下部无叶**：竿身下部 40% 无枝无叶
5. **叶在枝端**：叶子只长在小枝末端，不直接从竿上长出
6. **叶形成披针形**：长宽比 ≥ 5:1，叶尖渐尖有锋
7. **字法可辨**：至少能看出"个"字叶组（3叶一组向上展开）
8. **三竹不等距不等高**：间距变异系数 >20%，高度差 >15%
9. **无 JS 错误**

### 5.2 评分维度（Checker）
- 竿相（节环/锥度/姿态）权重 1.5
- 枝法（出枝位置/弧度/钉头鼠尾）权重 1.0
- 叶形（披针形/C弯/出锋）权重 1.0
- 叶组（个字法/疏密/叠破）权重 1.0
- 叶势（朝向/风势/冠形）权重 1.0
- 墨色（浓淡干湿/无鬼影）权重 1.5
- 构图（主次/藏露/留白）权重 1.0
- 气韵（宋画意境/笔意）权重 1.0

### 5.3 目标分数
- **底线 6.5**（形态正确，渲染尚可）
- **目标 7.5**（形态正确 + 渲染有笔触感 + 构图有画意）
- v11.2 的 5.40 主要因形态错误拉低，v12.0 修正形态后预期竿相/构图/叶组/气韵大幅提升

## 六、执行策略（ROI 铁律）

1. **基线锁**：先 `cp ink-garden.html ink-garden.html.bak-v11.2-final` 锁定 v11.2 渲染成果
2. **分模块交付**：
   - P1（竿+节）：重写节间距 + 锥度 + 节环渲染 → 截图验证"有节的光竿"
   - P2（枝）：重写出枝位置 + 长度梯度 + 弧度 + 雀爪 → 截图验证"竿+枝骨架"
   - P3（叶）：重写叶形 + 字法排列 + 叶量控制 → 截图验证"完整竹"
   - P4（构图）：调整三竹配置 + 留白
3. **每阶段单独截图验收**，不一次全改（v11.0 同时改 3 函数崩盘的教训）
4. **保留 v11.2 渲染层**：brushPath 双 pass/stamp/飞白代码尽量不改，只改 buildBamboo 形态数据和节环绘制层级
5. **数据驱动**：用 `window._plants` 输出每竿的节数/节间距/出枝位置/叶数，验证形态参数正确（不靠猜）

## 七、不做什么（避免 scope creep）

- v12.0 **不做**叶片 brushPath 笔触化（留 v12.1）
- v12.0 **不做**风/雨/雪/雾等气候变体
- v12.0 **不做**竹笋、根、石、苔等陪衬
- v12.0 **不改**兰/梅/松/柳等其他物种
- v12.0 **不重构** Command Bus 架构
- v12.0 **不修** dispatch opts 传递 bug（在 P4 构图阶段顺便验证，不单独花时间）
