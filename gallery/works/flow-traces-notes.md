## 一句话

一团墨粒子被看不见的流场推着走，在宣纸上拖出层层叠叠的笔触痕迹；鼠标靠近会卷起涡旋、喷一点朱砂。满纸是缓慢流变的墨痕与呼吸感的留白。

## 场景 / 玩法

纯生成 + 交互的 Flow Field（流场）粒子玩具。1600 个粒子沿 Perlin 噪声给出的角度向量运动，半透明纸张色 overlay 让旧痕慢慢沉淀成墨迹积累。画面无固定物象，东方感来自五层墨色调色板、宣纸纹理、宋体标题「流痕」与朱砂「绒球」印。

与墨园（确定性构图、宋画竹子）刻意拉开方向：墨园是「画好的画」，流痕是「一直在生成的画」。

## 交互

- **鼠标移动**：200px 半径内施加涡旋 + 推力组合（60% 推 + 50% 旋），鼠标处喷发朱砂粒子（朱砂约 6% 全局概率 + 鼠标处 40%）。
- **双击**：清空画面重来。
- **右上角「重新」按钮**：重置。
- 支持 touch 事件与 resize 响应；移动端未做粒子数自适应（见已知边界）。

## 物理 / 绘制要点

- **Perlin Noise 3D 流场**：Ken Perlin 经典实现，x/y 决定空间角度，z 随时间缓慢推进（ZOOM=0.0008），得到「缓慢流变」而非急转。
- **粒子物理链**：噪声场角度 → 力 → 阻尼 0.93 → 速度上限 3.0×speed → 位置更新；每粒子独立位置/速度/颜色/大小/生命周期。
- **速度 → 笔触粗细**：`size = baseSize × (1.2 − speed_ratio×0.6)`，快则细如飞白、慢则粗如积墨。
- **五层墨色调色板**：按权重分配，焦墨 6% 到灰墨 20%；朱砂做极小比例暖色点缀。
- **拖痕积累**：每帧半透明纸张色 overlay（alpha=0.008），旧迹渐隐但不瞬清，形成长拖痕的积墨感；TRAIL_FADE≈0.008 是墨迹积累与画面呼吸的甜区。
- **纸张纹理**：256×256 离屏 canvas 生成 ±6 RGB 微噪声，createPattern 平铺。
- **粒子淡入 40 帧 / 淡出 60 帧**；UI 用 CSS 动画渐入（标题延迟 1s、印章 2s、按钮 2.5s），避免初始突兀。
- DPR 上限 2，Canvas 2D 在 1600 粒子下性能良好。

## 参照系

- Manfred Mohr 的算法绘画、openprocessing.org 上的 flow field 作品（流场作为经典生成艺术技术）。
- 东方化判断（当日明确）：flow field 算法本身是中性的当代生成艺术，「东方感」主要靠调色板 + 纸纹 + UI；要更进一步东方化需笔触级渲染（可接墨园 brushPath 引擎），简单 lineTo 的 round cap 段没有真正的提按顿挫。

## 本轮调参记录（诊 → 磨，写后即诊五轮）

1. 疑惑 Perlin 在整数坐标返回 0（晶格点），验证后确认是正确行为，非 bug。
2. 初版 1800 粒子、TRAIL_FADE=0.012 拖痕消失太快 → 改 1600 粒子、FADE=0.008，墨迹更持久。
3. 初版无速度→粗细映射、所有线等宽显机械 → 加速度映射函数。
4. 纯色背景显平 → 加纸张微噪声纹理。
5. UI 初版立即显示突兀 → 改 CSS 渐入（标题/印章/按钮分时延）。

## contribution（可复用）

1. **作品本身**：交互式 flow-field 生成艺术模板（单文件 Canvas，可复用为后续互动网页 / 小玩具）。
2. **审美判据**：中性生成艺术算法的「东方感」主要靠调色板 + 纸纹 + UI；判据层面承认 lineTo 圆头线到不了笔墨提按，须换笔触引擎。
3. **工具参数锚点**：Canvas 2D + 半透明 overlay trail fade 在 1600 粒子下性能良好；TRAIL_FADE≈0.008 为积墨/呼吸甜区；Perlin 3D 的 z 推进 0.0008–0.001 适合缓慢流变。
