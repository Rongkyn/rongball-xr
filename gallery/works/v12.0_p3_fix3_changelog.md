# 墨园竹子 v12.0 P3-fix3 — Changelog

**日期：** 2026-08-15
**基线：** P3-fix2（ink-garden.html.bak-p3-fix2）
**目标：** 修复"双线轮廓/空心描边"P0 渲染伪影（大众与专家两轨评审一致指出叶边深、中间浅，像勾线没填色）。

## 根因

双线/空心伪影由三层叠加：

1. 叶片 fill 的 globalAlpha 偏低（`a = baseOpacity × (0.92~1.0) × leafAlpha`），canvas 在半透明填充边界做抗锯齿，产生比 fill 本身更深的边线；
2. 中脉用 `INK.zhong (#443a30)` 画在叶身上，与边缘抗锯齿线形成"双线"；
3. 叶尖与折叶后半段 0.8 / 0.85 位置都有 0.95 透明度台阶，多叶片半透明重叠时边缘叠加更深。

## 修复项

### Fix-1 提高叶片填充不透明度（🔴最关键）
- 随机因子从 `0.92 + rand×0.08` 收窄到 `0.97 + rand×0.03`，最低 alpha 提升约 5 个百分点；
- 外层 `Math.min(1, …)` 兜底；
- 非折叶 `leafGrad` 0.8 位置由 `rgba(inkRGB, 0.95)` 改为纯色 `drawFill`，去掉透明度台阶；
- 折叶后半段同步修改（见 Fix-3）。

### Fix-2 中脉改为留白处理
- 旧：`ctx.globalAlpha = 0.50*a`、`strokeStyle = INK.zhong`、线宽 0.5–0.8px 深色线；
- 新：在 clip 的叶形路径内，用 `destination-out` 以 `globalAlpha = 0.12–0.18` 擦出一条 `maxHalf*0.08` 粗的极细留白中脉，模拟毛笔腹过留白；
- 触发条件：`len > 40` 且 `leafTone !== 'dan' && leafTone !== 'qing'`；
- clip 路径在 fill 之后重新构造（`tracePath(leftPts)+tracePath(rightPts)`），因为前一次 fill 的 path 已被消耗；
- `ctx.restore()` 后恢复 `globalAlpha = a`，保证后续绘制不受影响。

### Fix-3 折叶后半段对比加强
- 后半段由 `INK.dan (#6b5e4c)` 改为 `backInk = INK.qing || '#a89b82'`（`#9a8d76`，比淡墨更浅）；
- 0.85 位置的 `rgba(danRGB, 0.95)` 改为纯色 `INK.dan`（折点附近略深）；
- 终点 1.0 仍为 `INK.zhong`，形成"清→淡→中"的渐深过渡；
- 前半浓墨+后半清墨形成强烈正反对比。

### Fix-4 叶间墨色两极分化（_addBambooLeafCluster）
按竿高 `upFactor` 分级的 leafTone 比例从"浓墨偏多"调整为"中墨为骨、浓淡两极"：

| upFactor | 旧 nong / zhong / dan | 新 nong / zhong / dan |
|---|---|---|
| < 0.30 (下段) | 55 / 22.5 / 22.5 | 30 / 49 / 21 |
| < 0.60 (中段) | 40 / 30 / 30 | 25 / 56.25 / 18.75 |
| ≥ 0.60 (上段) | 25 / 33.75 / 41.25 | 20 / 60 / 20 |

视觉上中墨占比从 ~29% 提升至 ~55%，浓墨与淡墨各保留约 20–30% 的两极，画面不再灰成一片。仅修改 3 行概率参数，函数结构与形态参数未动。

### Fix-5 叶片边缘微不对称
在采样循环中给右侧边缘加微小随机偏移：

```js
const rightFactor = 0.88 + this.rand(b.id+n*43+t*100)*0.18; // 0.88–1.06
const rHw = hw * rightFactor;
rightPts.push({ x: cx - nx*rHw - nx*asym, y: cy - ny*rHw - ny*asym });
```

- 非折叶与折叶两个分支都应用；
- `leftPts` 保持原 hw，维持主势稳定；
- 右侧在 12% 收窄到 6% 放宽之间抖动，消除机械镜像感；
- 折叶分支不使用 asym（折叶原本也没有）。

## 后续观察

- 留白中脉（destination-out 0.12–0.18 alpha）在浓墨叶上效果自然，在中墨叶上可能偏淡；若评审反馈中脉不可见，备用方案是用比叶身 fill 深一阶的墨色（nong→jiao、zhong→nong）以 alpha 0.25、线宽 0.3–0.5px 画细线；
- 若折叶后半段清墨对比过强显得"翻白"，可将 `backInk` 由 `INK.qing` 回退到 `INK.dan` 与 `INK.qing` 之间的插值。
