# v12.0 P3 修复 Changelog

## P0

### P0-1 叶片宽度 2 倍 bug（最致命）
- 原 halfWRatio = (n===0?0.16:0.13) + rand*0.02 → 全宽 0.26–0.36（叶如豆瓣/虫子）。
- 修复：halfWRatio = (n===0?0.08:0.065) + rand*0.01 → 半宽 0.06–0.09，全宽 0.12–0.18。主笔 0.16–0.18、副笔 0.13–0.15，符合长披针形 5:1+ 长宽比。

### P0-2 叶尖急收锋线
- 中段缓收终点由 t=0.85/hw=0.55 改为 t=0.82/hw=0.45。
- 末段 pow(k, 0.7)→pow(k, 0.35)，18% 长度内迅速收为针尖；t=1.0 严格返回 0。

### P0-3 C 形弧弯可见性
- 控制点垂直偏移 len*0.06 → 主笔 0.14、普通 0.16、外层再加 0.02（即 0.18）。
- curveBase 0.08+age*0.10 → 0.12+age*0.14（约 7–15°）；外层 curveOuter 0.08–0.16 → 0.06–0.12，最多约 21°。
- 删除 sin(πt)*0.08*rand*2 随机 sag（它会抵消 C 形方向感）；控制点方向 ang+π/2*sideSign 与 curve*sideSign 保持一致。

### P0-4 折叶正反面渲染
- 折叶不再整叶用 INK.dan 平涂。改为按 t=0.40 拆成两段独立路径：
  - 前半段（柄→折点）：使用原 tonePlan 的 nong/zhong 墨色渐变（柄→折点）。
  - 后半段（折点→尖）：强制 INK.dan 基色，末段渐至 INK.zhong，表现翻起的叶背。
- 两段均走 Catmull-Rom 平滑，折点索引 round(0.40*N)，共用边界无裂缝。
- 折点处叠加 0.5px INK.nong alpha 0.40 的短横折痕线。
- foldAngle 保持 0.45–0.65。

### P0-5 叶量（主竹 40–60、辅竹 25–40、远竹 10–20）
- buildBamboo 出枝 skipRate：主竿 0.35→0.20；矮竿中部 0.10→0.05、上部 0.25→0.15。
- 雀爪：nodeT 窗口 0.55→0.60；概率 40%→60%；subN 由固定 1 改为 50% 概率 2 根。
- isShort 判定由 `!isMain && hMul<0.75` 改为 `hMul<0.85`，使 stalkCount=1 的矮竹（辅/远）也走矮竿密枝路径。
- _addBambooLeafCluster 字法分布：人 30%→25%、个 50%、介 20%→25%（叶均量 2.95→3.0）。
- 修复 addStem 非兰花路径未透传 heightMul/lean/stalkCount 的 bug（原先只复制 seed/instant，导致所有构图参数失效）。
- 叶簇数：主 20、辅 11、远 6；叶量：主 56、辅 37、远 17（CDP 实测，均在目标区间内）。未回到 200+ 片状态。
