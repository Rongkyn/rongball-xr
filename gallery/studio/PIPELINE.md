## 字段约定

- **出口**：产品（小程序/小游戏/Web）｜内容IP（AI 生图/视频账号、短剧）｜开源（独立新仓库）｜平台发行（Pico/Steam）｜简历叙事｜组合
- **背书等级**：⭐ 可探索 ｜ ⭐⭐ 值得做原型 ｜ ⭐⭐⭐ 进短名单（建议主人圈选）
- **状态**：候选 → 立项 → 原型 → 进短名单 → 主人已圈选 → 上线/发布 → 运营中
- 进短名单门槛：30 秒内能让外行看懂价值；产品件有最小可用闭环；内容件有角色圣经+样片数据；开源件满足「库 + 30 秒 demo + 英文 README + 正式 release」；XR 件有可装包完整体验。
