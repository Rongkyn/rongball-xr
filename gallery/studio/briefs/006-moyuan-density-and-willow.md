# Brief #006 — 墨园 v3.2：从草稿到成品

## 诊断
v3.1笔墨语言逻辑正确（全墨色/楔形竹叶/扇形松针/胭脂一点红/远山晕染），
但被用户评价为"太像刚开始做的草稿"。根因：

1. **笔墨密度太低**——每株竹只有6-12组叶，松只有十几束针，梅只有几朵花。
   宋画一竿竹有数十组叶片，一棵松有上百束针。
2. **柳树形态完全错误**——buildWillow生成的是向上分叉的枝，没有"万条垂下"的垂帘感。
3. **线条均匀干净**——像矢量线稿，缺粗细变化、飞白、干湿浓淡。
4. **构图像标本**——6株等距排列，无主次聚散。
5. **梅花缺虬曲**——Y形细枝，无老干嶙峋感。

## 目标
从草稿级别提升到可展示的宋画水墨小品。笔墨密度翻倍，柳树真正垂下来，
笔触有生命力，构图有主次。

## 文件
- 源文件：`gallery/works/ink-garden.html`
- 当前版本：v3.1（约63KB）
- 文件大小限制放宽到 **75KB**
- 目标版本：v3.2

## P0 修改要求

### 1. 柳树彻底重写 `buildWillow()`
当前buildWillow虽然生成了arching branch + drooping twigs，但：
- arching弯度不够，看起来还是向上的枝
- drooping twig数量太少（每根主枝只有1-2根垂枝）
- 垂枝太短（45-100px）

重写要求：
- 短粗主干：高20-30px，width=8-10，几乎是一个"树桩"
- 主干顶部直接分出3-4根"弓枝"（cascade branches）
- 每根弓枝：先向上向外伸展30-50px形成拱形最高点，然后弯转向下延伸40-80px
- 从弓枝的**每个节点**（每隔6-8px一个节点）生一根柔条
- 柔条：垂直垂下，长度80-140px（近树冠的短、远端的长），用7-10段贝塞尔曲线，自然微弯
- 每根弓枝有8-15个节点→8-15根柔条
- 整株柳树约30-50根柔条，形成蓬松垂帘
- 柔条lineWidth=0.8-1.5，颜色INK.dan~INK.zhong
- 柔条上每隔10-15px点一个笔尖小叶：tiny ellipse 1.5-2.5px，INK.dan，随机偏移
- 弓枝本身width=3-5，颜色INK.zhong，有粗细变化
- 整体效果：像一个绿色（墨色）的喷泉/垂帘，不是向上的树

### 2. 竹子加密 `buildBamboo()` + `drawBambooLeaves()`
当前：2-4竿，每竿5-6节，每节60%生1根短侧枝（14-32px），每根侧枝只在顶梢有一组叶。
问题：叶量太少。

修改：
- 每竿7-8节（原5-6节）
- 每节85%概率生侧枝（原60%），50%概率生**对生双侧枝**（左右各一）
- 侧枝更长：25-50px（原14-32px），侧枝本身有2-3个分岔
- 每个分岔顶梢都有一组叶（不是只有侧枝顶端一组）
- 整竿竹目标：40+组叶片
- 每组叶片5-7片（原3-5片），叶片更长14-22px（原约10-14px）
- 竹叶楔形笔触保持，但增加大小变化：部分叶宽3px部分1.5px
- 竹竿加粗：baseWidth=6.5（原6改到了6），竹节横痕更明显（lineWidth=2→2.5）
- 竹色：老竿INK.nong，新枝INK.zhong，叶INK.nong~INK.jiao有浓淡

### 3. 松树加密
当前：松针束太少，枝干偏直。

修改species参数和drawPineNeedles：
- baseLen=78（已改），baseWidth=14（原13）
- branchChance=0.95（原0.9），midBranchChance=0.45（原0.35）
- doubleBranchChance=0.6（原0.5）
- curve=0.035（原0.025）——更虬曲
- 每束松针10-14根（原8-12），针长18-26px（原14-20）
- 松针束密度×3：在drawPineNeedles中，除了tip的针束，在branch路径中间
  每隔2-3个节点也画一束小针束（尺寸为tip束的60-70%）
- 整株松目标：30+束松针
- 松鳞皮和苔点保留，苔点增加密度

### 4. 梅花虬曲化
当前：通用growBranch生成的Y形细枝。

修改species参数：
- baseWidth=10（原9），branchAngle=0.8（原0.7），angleVariance=0.45（原0.35）
- lengthRatio=0.58（原0.62），curve=0.035（原0.02）
- branchChance=0.95（原0.92），doubleBranchChance=0.6（原0.55）
- segments=5（原4）
- 花量：每株15-25朵（需要增加drawPlumBlossom的调用频率）
  - 在hasLeaf的branch tip画花，且在branch中间节点也有概率画花
  - 70%淡墨白瓣、25%墨梅（INK.nong瓣）、5%胭脂红（整株1-2朵）
- 花朵稍大：6-9px（原约5-7px）
- 保持疏朗：花朵之间最小间距20px，不要密集成球
- 老干上可加少量苔点

### 5. 兰花加密
当前：3-5片叶，像对勾线。

修改buildOrchid：
- leafCount=5-7片（原3-5）
- 最长叶160-220px（原baseLen=140）
- 长短错落：第一片最长，之后递减，最短的60-80px
- 叶宽2-4px，起笔粗重（lineWidth=4→迅速降到2），收笔尖细（lineWidth=1→0.5）
  模拟"钉头鼠尾"
- 叶片弧度更大：baseAngle范围扩大到±1.8rad（原±1.5）
- 加2-3朵淡墨小花在叶丛中：5瓣小花，直径5-7px，INK.qing~INK.dan
- 叶片颜色有浓淡：老叶INK.nong，新叶INK.zhong

### 6. 笔触肌理（所有植物）
当前线条均匀，像矢量。增加：

- **起笔收笔变化**：每段枝条lineWidth从baseWidth的100%渐细到60%，
  模拟书法用笔的按→提
- **飞白**：在枝条路径上，用lineCap='round'配合随机的globalAlpha=0.3-0.7
  短断笔，模拟干笔飞白。约15%的枝条段有飞白效果
- **墨色浓淡**：同一株植物内，depth=0的老枝用INK.jiao/nong，
  depth=2的新枝用INK.zhong/dan，叶片用nong~jiao但有±15%明度随机变化
- **叶片浓淡节奏**：不是所有叶同色，随机70%浓墨30%淡墨，形成节奏

### 7. 构图改善
自动播种starters从6株改为3株，有主次：
```javascript
const starters = [
  { x:0.72, yRatio:0.58, si:1 },  // 松 右中——主角，最大
  { x:0.22, yRatio:0.72, si:0 },  // 竹 左偏下——配角
  { x:0.12, yRatio:0.80, si:4 },  // 兰 左下——点缀
];
```
松为主（大），竹为客（中），兰为衬（小）。形成右实左虚的宋画构图。
不种柳和梅在默认场景中——留给用户自己种。
