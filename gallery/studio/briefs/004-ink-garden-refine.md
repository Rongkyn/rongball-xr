# Brief #004 · 墨园 v2「做好」迭代

**作品**：ink-garden.html（当前 45,957 字节，已通过三轮代码攻墨）
**类型**：创作工具（冥想性生成艺术）
**命题转变**：从「做出来」到「做好」。三轮攻墨保证了代码正确，但从未以创作者身份真正种过一座园子。亲验后发现产出物不好看，这是比任何 bug 都严重的问题。

## 亲验证据（绒球作为 creator + player）
在云电脑真实浏览器中种植梅/兰/竹/松后截图观察，问题：
1. **风太猛**：柳树冠被整体吹向一侧，像台风而非微风拂柳。effWind×8 位移系数过大；阵风 gustStrength 0.4-1.0 过强；direction 70%向右导致永远单侧吹。
2. **竹像枯枝**：仅两根细杆、零星小叶，没有竹的丛生感和竹叶层次。baseLen=55 偏短，leafDensity=0.7 但叶集中在末梢。
3. **松像灌木**：缺乏松树的层叠姿态，针叶只有5条短线呈星状，看不出松针簇。
4. **梅看不到花**：blossomColor 是灰色 #8a8075，花和枝色差极小；花仅在 depth≤2 末梢，整株可能只有一两朵；尺寸 1.5×baseLeafSize 仍偏小。
5. **兰特征弱**：maxDepth=4 但 branchChance=0.4，常常只长出一两片长叶，不像一丛兰草。
6. **构图失衡**：随缘初始3株 + 手动种植都挤在画面下半部，上半屏大面积留白，头轻脚重。
7. **无法撤销单株**：种坏了只能清园重来，作为创作工具这是致命缺陷。

## 改进目标（按优先级）

### P0 视觉形态——每种植物必须一眼可辨且有姿态
- **风**：大幅减弱。base strength 区间降到 0.08-0.25，gust 降到 0.15-0.35，位移系数从 ×8 降到 ×4；direction 改为 50/50，让风有来有回；微风才是水墨的气质。
- **竹**：增加丛生感（一株竹应在基部萌发2-3根主杆），竹叶加密并分布在杆的中上部多个节而非仅末梢，叶子要有浓淡层次和向背。
- **松**：增加枝干的横向伸展和层叠（松树姿态贵在"奇"——斜出、舒展、有断有连）；松针改为簇状，每簇多根细密针叶成扇形放射，而不是5条孤立短线。
- **梅**：花改为淡朱红/胭脂色系（参考国画梅花，如 `#9a4442`/`#b85c5a`），与墨枝形成对比；增加花的数量和分布（老枝、新枝都可有花）；花朵尺寸放大；可点少量花苞。
- **兰**：改为基生丛叶形态（多片长叶从根部放射状长出，长短交错、有正有斜有弯垂），而非分形树枝结构；叶色清雅。
- **柳**：细枝加柔、下垂感加强，风一吹是万千枝条同向轻摆而非整棵树平移。

### P1 创作工具能力
- **撤销单株**：加"撤"按钮（或 Ctrl+Z / 右键撤销），移除最近种下的一株；保留"清园"。
- **构图引导**：随缘初始播种时，植物分布范围扩展到画面纵向 40%-85% 区域（而非只在地面线附近），高低错落；手动种植位置完全由用户决定，不做限制。

### P2 氛围
- 风指示器数值与新风系统同步调小。
- 落叶/飘叶频率随风速变化（微风偶有一叶，大风才有多叶）。

## 约束
- 单文件 HTML Canvas 2D，不引入外部库和图片资源。
- 文件控制在 60KB 以内。
- 保持现有 DPR 适配、印章、留影PNG导出、十二时辰、密度检测等已修好的机制不被破坏。
- 梅花的朱红要克制，是"墨梅一点红"的意境，不是满树红花。
- 整体审美：水墨意境优先于物理仿真；留白、浓淡、姿态比"画得像"更重要。

## 验收要点
1. 每种植物种下去一眼能认出是什么。
2. 风是微风，植物轻摆而不被吹歪。
3. 梅有红色花点，在水墨画面中是视觉焦点。
4. 竹成丛、松有姿、兰飘逸、柳柔美。
5. 撤按钮能正确移除最近一株，可连续撤销。
6. `node --check` 通过，无控制台报错。
7. 文件 ≤60KB。
