# Brief #007 — 墨园 v3.3：聚散节奏

## 诊断
v3.2的核心问题不是密度不够，而是**没有节奏**。
Maker把"加密"理解成"加数量"，结果竹叶糊成黑色刺猬球。
松之所以好（7.5分），是因为针束之间有呼吸感；竹之所以差（4分），
是因为40+组叶全堆在一起，组与组之间没有留白。

宋画竹的核心：**疏可走马，密不透风**。不是每节都长叶，
不是每根侧枝都有叶，叶组之间要有明显的空气感。

## P0 修改

### 1. 竹叶聚散节奏重写 `buildBamboo()`

当前问题：85%节点生侧枝、50%对生双侧枝、每枝3-4个分岔→叶子全糊在一起。

重写逻辑——引入"竿相"概念，每竿竹随机一种性格：

**竿相A · 疏竿（40%概率）**：
- 7节，但只有顶端3节生侧枝（下部4节裸露，只画竿和节）
- 每节只生单侧枝（不对生）
- 每根侧枝只有1-2个分岔，每分岔1组叶
- 整竿约8-12组叶，疏朗雅致
- 叶片偏大偏长（18-26px），每组4-6片

**竿相B · 整竿（40%概率）**：
- 8节，中部4节生侧枝（底部2节裸露、顶部2节为梢）
- 侧枝对生率30%
- 每根侧枝2-3个分岔
- 整竿约18-25组叶，有聚有散
- 叶片中等（14-20px），每组5-7片

**竿相C · 茂竿（20%概率）**：
- 9节，中上部6节生侧枝
- 侧枝对生率50%
- 每根侧枝3-4个分岔
- 整竿约30-40组叶，但**叶组沿侧枝方向呈扇形展开**，不堆在同一位置
- 关键：分岔角度要大（0.8-1.4rad），让叶组在空间上散开，不重叠
- 叶片偏小（12-18px），每组5-7片

**所有竿相通用**：
- 叶组之间的间距≥叶片长度的0.8倍（通过分岔长度控制）
- 相邻节点的侧枝方向交替（左→右→左），避免同侧堆叠
- 竹节以下（底部2节）永远裸露，只有竿和节痕
- 竿与竿之间错开：主竿最高，副竿矮10-20%，第三竿更矮或更偏
- 竹叶的浓淡节奏：每组叶随机70%浓(nong) 30%淡(zhong)，但同一组分岔上的叶同色，形成色块节奏

### 2. 兰叶力度重写 `drawOrchidLeaf()` + `buildOrchid()`

当前问题：5-7片叶但视觉上还是几根细线，没有书法力量感。

buildOrchid修改：
- 叶片数保持5-7片
- 但叶片长短差异更大：
  - 第1片（主叶）：180-240px，弧度大，从根部向上再优雅地弯向一侧
  - 第2片：140-180px，反方向弯
  - 第3片：120-150px，较直立
  - 第4-5片：80-120px，短而聚拢，称为"凤眼"或"鼠尾"
  - 第6-7片（如有）：60-90px，最矮，护根
- baseAngle范围：主叶可以弯到接近水平（±2.0rad），不要都竖着

drawOrchidLeaf修改——真正的钉头鼠尾：
- 当前的taper逻辑不够明显。重写lineWidth变化：
  - 0-5%段：lineWidth从0快速升到4px（落笔，钉头）
  - 5-15%段：lineWidth保持3.5-4px（按笔，实）
  - 15-60%段：lineWidth从3.5渐降到2px（行笔，中实）
  - 60-90%段：lineWidth从2px渐降到0.8px（提锋）
  - 90-100%段：lineWidth从0.8降到0.3px（收笔，鼠尾尖）
- 用多段lineTo逐段设置lineWidth（不能用单条path的渐变width，
  需要把叶子分成15-20段，每段ctx.lineWidth不同）
- 叶片颜色：老叶INK.nong（焦浓），新叶INK.zhong（重墨），
  最嫩的小叶INK.dan（淡墨）——浓淡层次分明
- 叶尖加一个微小的回锋点：在叶片终点画一个1px的点，模拟书法收锋

### 3. 松树微调（已经7.5分，不大改）

- 松针束很好，保持
- 唯一调整：松针的墨色可以增加一点变化——每束针随机60%INK.nong
  40%INK.jiao，不要全是同一个黑
- 松枝的飞白效果保持

### 4. 构图微调

starters保持3株，但调整位置和大小比例：
```javascript
const starters = [
  { x:0.70, yRatio:0.55, si:1 },  // 松 右偏中——主角，占画面主体
  { x:0.20, yRatio:0.70, si:0 },  // 竹 左偏下——客，比松矮
  { x:0.08, yRatio:0.82, si:4 },  // 兰 最左下——衬，最小
];
```
松的yRatio从0.58调到0.55（稍微往上，让松冠有空间展开）。
