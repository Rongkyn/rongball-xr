# Brief #001 · 山居 · Mountain Dwelling

## 一句话概念
水墨山水经营模拟——在一卷宣纸上种竹、引水、筑舍、待客，看四季流转、山居自长。

## 核心交互
玩家在一幅横向展开的水墨山水中：
- **点击空地**放置元素：竹、松、梅、石、溪、舍
- **拖拽**调整位置
- **时间流逝**：画面自动经历春/夏/秋/冬，元素随季节变化（竹在春雨后长高、梅在冬雪开花、溪流在冬结冰）
- **来客事件**：隐士、诗人、行者会到访，根据山居布局留下不同反应（题诗、品茶、长啸）
- **无胜负、无目标分数**：这是一个"养"的小品，观察山居自己生长、四季轮转

## 水墨美学要求
- 底色：宣纸米白/微黄，带细微纤维纹理
- 墨色：焦浓重淡清五级，元素用不同墨色分层（远山淡墨、近树浓墨）
- 留白：画面 50% 以上是留白，元素稀疏，呼吸感
- 动效：缓慢、有机，像水墨在纸上晕开；不要弹跳/快速缓动
- 四季色调：春淡青、夏浓绿、秋赭石、冬淡灰蓝
- 印章：右下角朱红印章"山居"

## 本作新探索方向
1. **模拟系统**：第一个有"时间"和"自主变化"的作品（前5作都是即时交互）
2. **经营/放置类玩法**：呼应策略经营兴趣，但做极简艺术化版本
3. **季节系统**：程序化时间驱动视觉变化
4. **NPC AI 行为**：来客根据布局做简单判断（虽然是规则而非LLM）

## 技术约束
- 单文件 HTML，所有 CSS/JS 内联
- 不依赖外部 CDN（或仅用稳定 CDN 并做 fallback）
- Canvas 2D 渲染山水和元素（DOM 用于 UI 控件）
- 桌面端鼠标 + 移动端触摸都可用
- 性能：60fps，元素数量上限合理
- 文件大小 < 500KB

## 验收要点
1. 能在山水上放置至少 4 种元素（竹/松/溪/舍），位置可拖
2. 四季自动轮转，每个季节视觉明显不同，元素有季节反应
3. 来客事件至少 3 种，根据布局有不同反馈
4. 水墨美学：留白 > 40%，墨色层次分明，动效缓慢有机
5. 桌面+移动端均可操作，无控制台报错
6. 单文件可独立运行
