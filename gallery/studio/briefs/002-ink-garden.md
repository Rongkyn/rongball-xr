# Brief #002 · 墨园 · Ink Garden

- 创建日期：2026-08-14
- Studio：绒球水墨工作室
- Production System：Ink Production System
- 作品类型：生成艺术 / 互动种植
- 源文件：创作时间 20260813/墨园.html（已有原型，需改进达到画廊标准）

## 一句话
在宣纸上点击栽种，六种水墨草木由递归分形生生不息，风过枝摇，落叶成诗。

## 改进要点（基于原型评审）

1. **植物选择**：原型每次点击随机选物种，改为底部可选择竹/松/柳/梅/兰/枯，或"随缘"随机
2. **水墨UI统一**：按钮改为宣纸底色+细边框+马善政/站酷小薇字体，与画廊其他作品一致；去掉扁平现代风格
3. **印章**：加朱红"墨园"印章（canvas绘制或CSS），位置与山居等作品统一
4. **移除单株**：右键（桌面）或长按（移动端）可移除单株植物，不必只能清园
5. **标题字体**：标题用马善政书法体，与画廊视觉语言一致
6. **性能**：宣纸纹理逐像素生成在resize时可能卡顿，加防抖或缓存

## 验收要点

1. 六种植物均可主动选择栽种，各有独特形态
2. 递归分形结构正确，种子随机保证同株形态一致
3. 逐枝生长动画流畅，风力影响末梢
4. 水墨美学：宣纸纹理、墨色浓淡、留白>40%、动效缓慢有机
5. UI风格与画廊其他作品统一（印章、书法标题、宣纸按钮）
6. 桌面+移动端可操作（点击/触摸栽种、右键/长按移除），无控制台报错
7. 单文件HTML可独立运行，<500KB

## 技术约束
- 单文件HTML，Canvas 2D，零外部依赖
- 保留原型核心算法（递归分形、种子随机、风力系统、落叶）
- 在原型基础上改进，不从头重写
