## 一、选题优先级（从上往下，上位未清空不得做下位）

1. **主人明确点题的件**
2. **求职作品集候选件深磨**：对齐 `求职准备/BACKLOG.md` P11–P15 —— 移动端适配、加载性能（单文件体积/图片压缩）、交互手感、叙事完整性（背景-我的角色-做法-成果四段式）
3. **其他积压旧作**：待实耳/实机校验件、长期待磨件（如墨洇再磨），按本看板队列排序
4. **Studio / 共享能力回流欠账**：notes 标了 contribution 但 `gallery/works/lib/POOL.md` 未收录、避坑未回流 harness 的
5. **以上全部清空后**，才允许开全新件

## 二、开新件硬闸（三条同时满足才放行）

- 待主人审阅队列 ≤ 2 件
- Review 区无积压超过 7 天的打磨项
- 节令/应景件须主会话当周明确批准（例：中秋桂雨已在 9/17 当周批准），创作 session 不得自行判定"应景"

闸口未过时，时段必须用于旧作打磨，简报写明「因积压未清新作闸，今日打磨 X」。不得绕道开新坑。

1. 成品当日 git 回仓 `Rongkyn/rongball-xr`（works 成品 + notes + 必要证据帧），禁止只存云盘日期夹
2. 挂廊 `gallery/index.html` 同步上架/更新卡片
3. intent / 迭代日志进 `gallery/studio/painting/process/件名/`
4. 验收复用 `gallery/works/lib/cdp-harness.js`；新踩的坑**当轮**回流 harness 本体并升避坑编号

6. 简报 notify 主会话：今日是新件还是旧作迭代、回仓 commit hash、待主人动作清单
