## 一句话意图

一张宣纸，点击落墨，墨晕扩散的同时琴弦拨动。横向位置定音高（五声音阶），纵向位置定力度。画即曲，曲即画。

## 视觉锚点（研）

- 古琴减字谱的空间感：音不只是时间序列，也是位置
- 水墨落纸的瞬间：墨从中心向外晕开，浓处焦黑、边缘渐淡
- 留白即休止：不点击的地方是纸的呼吸
- 参考：Karplus-Strong拨弦合成算法（1983），古琴音色特征为快速attack+悠长decay

## 核心交互

| 输入 | 映射 | 视觉反馈 | 音频反馈 |
|------|------|----------|----------|
| X坐标 | 五声音阶音高（C3-A4，10音） | 弦在对应高度闪烁 | 对应音高拨弦 |
| Y坐标 | 力度（0.3-1.0） | 墨色五档（清→焦），墨点大小，溅墨数量 | 音量+泛音层 |
| 点击 | 落墨 | 有机形状墨晕+涟漪+弦段振动 | Karplus-Strong合成+卷积混响+立体声Panner |
| 空格键 | 随机落墨 | 同上 | 同上 |
| 清纸按钮 | 清除所有墨痕 | 纸归白 | — |
| 微风按钮 | 环境风粒子 | 微粒随风飘 | — |

## 技术要点

1. **Karplus-Strong合成**：噪声填充延迟线 → 平均滤波循环。阻尼系数0.995-0.9995（高音衰减快、低音延音长），三角波激励模拟近岳山拨弦
2. **泛音层**：velocity>0.45时叠加高八度KS弦，模拟泛音（fan yin）
3. **卷积混响**：自生成2.5秒指数衰减脉冲响应，25%湿声
4. **立体声Panner**：低音在左、高音在右，空间感
5. **墨滴渲染**：24点有机多边形（三层正弦叠加变异）+径向渐变（焦核→墨身→晕染边缘）+飞溅小点
6. **弦振动可视化**：拨弦点附近35%屏宽的局部弦段，三角形包络衰减，0.4秒视觉消退（远快于音频延音）
7. **宣纸纹理**：离屏Canvas预渲染256px噪声tile + 暖色晕光，静态背景每帧只drawImage
8. **DPR自适应**：限制最大2x，高分屏清晰

## 自评（裁）

### 得（5条）

1. **音画同步成立**：落墨即拨弦，不是两个独立系统拼贴。墨色深度对应力度、墨点位置对应音高，视觉和听觉是同一事件的两面
2. **水墨美学延续**：宣纸底色#e8dfc8、墨色五档、胭脂点缀、朱红印章、宋体标题，与画廊其他作品一脉相承
3. **古琴音色有质感**：KS算法+长延音+泛音+混响，不是廉价电子蜂鸣。低音悠长、高音清越
4. **留白即交互**：不点击的区域是纸的呼吸，这与水墨精神一致
5. **单文件零依赖**：21.9KB，打开即玩，移动端可用（pointer events）

### 失（4条）

1. **弦振动视觉在快速弹奏时仍可能偏杂**：10个音快速连弹时弦段叠加，virtual-time截图可见多条线。真实使用中0.4秒消退，但快速演奏时仍可能略乱
2. **缺少音阶视觉参照**：用户不知道X轴对应什么音。顶部有9个tick但太微弱，无音名标注。新手需要探索
3. **墨点形状单一**：所有墨滴都是圆形有机变体，缺少长笔触、飞白等更多笔法变化
4. **无旋律引导/回放功能**：只能即兴演奏，不能录音回放，也没有预设示范曲

### 分数：7.5/10

第一眼不需要解释就知道"这是一个可以在宣纸上弹琴的东西"。7分门槛通过。未到8分因为弦线在密集演奏时仍可能显杂、缺少音阶引导。

## Contribution声明

**级别：工具级 + 作品级**

1. **作品本身**：可交付的交互式视听小品，古琴音色+水墨美学结合，可分享给主人
2. **方法/工具（工具级沉淀）**：
   - Karplus-Strong JS合成模板（噪声激励+平均滤波+动态阻尼+泛音层+卷积混响），可复用于未来音频项目
   - 墨滴渲染函数（有机多边形+径向渐变+焦核+飞溅），可提取为Ink Builder模块
   - 弦振动可视化模式（局部段+三角包络+快速消退）
3. **审美判据（Studio级）**：
   - 音画同步的关键：视觉消退必须远快于音频延音。听到3秒的音≠看到3秒的弦振。视觉是"事件标记"，音频是"回响"
   - 交互式水墨作品中，留白不是"没有东西"，而是"等待被触碰"
4. **新问题**：
   - 虚拟时间测试环境（headless Chrome --virtual-time-budget）不推进requestAnimationFrame，导致弦振动截图卡在最亮帧。未来交互作品截图验证需用真实async wait而非virtual-time

- `gallery/works/moyun-02-played.png`：演奏后，多枚墨滴+焦核+飞溅+涟漪可见
- `gallery/works/moyun-03-closeup.png`：墨滴局部特写

**亲验发现（与自评一致）**：
1. 弦振动0.4s消退在动图中只是一闪，确实比音频延音快，音画同步判据成立
2. 快速连弹时多弦段叠加略杂，验证了"失"第1条
3. 无音阶视觉提示，X轴对应什么音需要猜，验证了"失"第2条
4. 墨滴焦浓重淡清的力度层次在截图中可辨，高力度焦核明显
