# 绒球本印 v2 · Maker Report

> 画房Maker · v2从根重做
> 日期：2026-07-11
> 版本：block造型，废弃v1线描方向

## 一句话总结

从v1的"红线勾轮廓+卡通五官"彻底转向"红色块面造形+白线刻毛流"的古肖形印语言。绒球是一团有姿态的毛球，不是正圆卡通角色。

## 核心改动

### 废弃的v1代码
- `lineArt` 标志及相关逻辑
- `traceBallOutline` / `buildBallPath` 圆形+耳朵的几何拼接
- `drawBallDecor` 散布螺旋配饰
- `drawInnerEars` C形内耳线
- `dotEyes` / `arcEyes` 双眼+w嘴
- `jitteredArcTo` / `jitteredBezierTo` 线描抖动
- `rongballBase` 正圆身体+圆耳朵

### v2新增
- `block: true` 标志，pattern自带`render()`方法接管全部绘制
- `_buildSilhouette()`: 38个控制点+quadraticCurveTo拼出有机轮廓（梨形身体+不对称耳朵+底部圆润）
- `furLines()`: 9组簇、共约24条短弧线，模拟毛流，方向随身体弧度
- `drawEye()`: 单只极小圆点，偏右，无嘴
- `drawTail()`: 贝塞尔曲线尾巴+真内旋螺旋（从外向内收束，非同心圆）
- 朱文/白文各自独立的composite operation流程

### 朱文渲染流程
1. 红底填满
2. destination-out刻边框细线
3. destination-out刻白色动物剪影
4. destination-out刻眼睛
5. destination-out刻尾巴（红底上显白线）
6. source-over画红色毛流线（白色身体上显红线）

### 白文渲染流程
1. 画红色边框
2. 红色fill动物剪影
3. destination-out刻白色毛流线和眼睛
4. source-over画红色尾巴（白底上显红线）

## 形态设计

- **身体**：宽梨形/卵形，底部宽圆，顶部略收，非正圆。约占印面75-80%
- **左耳**：短、圆尖、略向外歪（高度约-0.62s）
- **右耳**：较高、较直立（高度约-0.68s）
- **两耳不对称**：右耳比左耳高约10%，左耳有外倾角度
- **眼睛**：单只小圆点，偏右上方，无嘴无鼻
- **尾巴**：从右腰甩出，贝塞尔曲线弯向右上角，末端真螺旋
- **毛流**：9组短弧线散布全身，疏密有致，跟随身体弧度方向
- **边栏**：厚单边栏（thick），线宽S*0.035

## 迭代记录（7轮）

1. **R1**：初版块面，但身体太窄高（像兔子/花瓶），耳朵太长，毛流像鱼骨
2. **R2**：改用点阵列+径向jitter，身体更圆但太小（约50%），边缘太瘤
3. **R3**：扩大patR，身体更满，但耳尖过尖，眼睛位置偏高
4. **R4**：进一步放大，圆化耳尖，修尾巴螺旋（donut问题），修白文tail bug
5. **R5**：修左耳分离问题，加宽身体，圆化底部
6. **R6**：整合耳朵到连续路径，加宽身体至0.56，圆化左耳
7. **R7（最终）**：微调眼睛大小（0.014s），收紧螺旋，定稿

## 已知局限

1. 左耳与身体的连接处仍有轻微"颈缩"，在quadratic曲线平滑下已可接受
2. 毛流线是弧线弧段，非虎纹那种平行排列——更随意更碎，符合绒球毛团质感
3. 做旧效果沿用v3的边缘侵蚀逻辑，未针对块面造型做特殊优化
4. 其他7个图案（yarn/sleep/roll/fluff/think/happy/sakura）仍为v1线描代码，未升级到block风格
