## 改了什么

### P0：耳朵结构重做（最关键）
- **废弃**旧方案（身体大圆 + 两个耳朵小圆分别stroke，导致双线交叉/眼镜效应）
- 启用 `buildBallPath()`：通过圆-圆交点数学，将身体弧与左右耳外弧拼成**一条连续闭合路径**，身体弧走到耳位顺势上扬成耳、到头回落接身体
- 四段弧（额头→右耳外→身体底部→左耳外）在交点处无缝衔接，端点不做jitter以保证拼接无穿帮
- 内耳廓改为**单条C形贝塞尔弧线**（`drawInnerEars()`），从耳外廓内侧起笔弯到另一侧内侧，不画整圆
- 头顶两耳之间无竖向拼缝
- 身体从0.55r放大至0.59r（+8%），更贴近边栏

### P1：金石刀刻味
- 新增 `jitteredArcTo()` / `jitteredBezierTo()`：沿路径采样密集点，每点加法线方向微抖动（振幅=线宽×6%），用quadraticCurveTo平滑连接，频率低不呈锯齿
- 主线与内耳弧均走jitter路径；配饰螺旋保持光滑（形成线质对比）
- lineCap/lineJoin = round，起笔收笔自然圆润
- 转折处由做旧系统的tiny notches模拟崩口（2-5px极小矩形，沿法线方向），不超过2处可见

### P1：做旧逻辑重做
- **删除**全屏随机白点/红点噪点逻辑（260个随机形状）
- 新做旧沿**边栏和线条边缘**发生：
  - 边栏：四边分布微小矩形缺口（顶/右侧磨损略重，底/左略轻），右上角1处自然断裂（3个重叠小blob模拟不规则崩裂），四角轻微磨圆
  - 身体轮廓线：8-12个极小notch（2-5px），沿径向法线方向，不形成大洞
  - 耳朵：0-2个tiny chip
  - 底面：仅5-9个极小砂眼（0.8-3.3px），稀疏分布
- aging=40时侵蚀量由新逻辑控制（不是全屏撒盐），密度适中
- 朱文：destination-out刻白缺口+红底砂眼；白文：destination-out刻红线缺口

### P2：配饰优化
- 螺旋从8个减至**6个**
- 两级大小：2个大锚点（s=0.075/0.072，约旧版1.2倍），其余3个中型（0.040-0.048），1个partial（15%-75%段，暗示被遮挡）
- 旋向混合：3个CW + 3个CCW
- **删除**3条短波浪线（thread ends）
- 新增**7个极小实心点**（印泥砂眼，d=0.008-0.014r）
- 疏密分布：左右两侧略密，顶部两耳之间留空，底部略密形成基座感
- 配饰在身体轮廓之前绘制，被轮廓线遮挡的部分自然消失（压线效果）

### P2：构图与边框
- 主体放大8%（bodyR 0.55→0.59），圆身更饱满
- 朱文双边框改为**单边框**：红色外框（约26px）+ 内部2px发丝白线界定，文粗边细节奏（主线约36px，边框约26px）
- 白文改为单rect stroke（旧evenodd双rect fill废弃），线宽约22px
- 删除圆形双圈逻辑

## 技术实现
- 仅改ball图案foreground/details + 新增jitter工具 + 重做applyAging + 边框逻辑
- 其他7个图案未动（仍用旧rongballBase/fill逻辑）
- 保留lineArt标志和destination-out刻白管线
- 单文件HTML零外部依赖
- 用seeded PRNG（mulberry32 + hashString）保证jitter和aging可复现
- ball几何通过window.__ballGeom传递给aging函数做线边侵蚀

## 遗留问题
1. **起笔收笔**：当前用round lineCap自然处理，没有做入刀粗/收笔钝的显式线宽渐变。如需更强的书法感可后续加两端圆点或lineWidth渐变
2. **崩口**：目前是在stroke后用destination-out挖小矩形，不是路径本身断开。远看自然，放大可见矩形边缘
3. **螺旋线质**：配饰螺旋保持光滑未加jitter，与主线有质感对比——这是有意为之，但如果评审认为配饰也应有刀刻感可统一加
4. **白文边框**：白文边框做旧缺口偏多偏长（右侧边缘可见几条明显白色短线），是因为edgeRoughCount对边框stroke的侵蚀效果在白底上更显眼。如需可降低白文边框做旧强度
5. **耳朵位置**：耳位偏上偏外（earAngle=0.62rad），造型偏"鼠"而非"猫"，与绒球本体设定吻合，但如果需要更圆更猫耳可收窄earAngle
