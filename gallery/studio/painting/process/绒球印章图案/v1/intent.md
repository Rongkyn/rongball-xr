# 绒球印章图案 v1 · 创作意图（研）

> 画房六步 · 第一步
> 日期：2026-08-16
> 参照：主人发的"金丝堂·鼠钱"肖形印（鼠抱元宝、铜钱散点）

## 一句话意图
把绒球八枚心情印章的图案，从"卡通填色块+表情符号"重做成"肖形印线描语言"——用自信、均匀的红线勾勒轮廓，造型凝练古拙，可爱靠比例与姿态，不靠五官表情和符号。

## v0为什么丑（诊断）
1. **填块不勾线**：绒球是一个红实坨，再挖白眼睛——像贴纸，不像印
2. **表情说太满**：Zzz、问号、腮红、爱心、弯月眼全上，图解化、幼稚
3. **构图空**：光杆一个球杵在印面中央，四周留白没有经营
4. **线条没自信**：边画边描的碎线，没有篆刻一刀下来的笃定

## 视觉锚点（对照鼠钱印与古肖形印）
1. **以线造型，线质第一**：主体用均匀、流畅、闭合的红线勾轮廓，内部留白；线宽统一且偏粗（约印面的3-4%），像鼠钱印那圈鼠身
2. **表情克制**：五官最多两个点眼+一条小弧线嘴，甚至可省略；禁止Zzz/?/♥/腮红/动作线等说明性符号
3. **可爱靠比例**：圆身、偏大的头/耳、短肢——用"形"本身卖萌，不挤眉弄眼
4. **散点配饰填满印面**：像鼠钱印的铜钱元宝那样，在主体四周用小纹样（毛线团、樱花、星点、月牙）补白，构图饱满有呼吸
5. **姿态暗示心情**：心情由身体姿态+配景传达，不由脸传达
   - 睡觉→蜷成一团+一弯月，不画Zzz
   - 思考→侧首/手托腮，不画问号
   - 开心→舒展上扬的姿态+小花星，不画大笑嘴
   - 炸毛→外轮廓变成锯齿/炸开的毛，不画O嘴
6. **印面饱满**：主体占印面60-75%，配景散点填满余白，不空

## 八个图案的新处理方向
| 心情 | 主体姿态（线描） | 散点配景 |
|------|-----------------|---------|
| 本体 | 正面端坐圆绒球，两耳，两点眼 | 四周几点短毛/星点 |
| 抱毛线 | 身略前倾抱螺旋毛线团 | 几个小毛线头、断线 |
| 睡觉 | 蜷成横椭圆、闭眼一道弧 | 一弯月、两三颗星 |
| 打滚 | 四脚朝天、圆身仰躺 | 周围几道短弧线（动感，非符号） |
| 炸毛 | 外轮廓锯齿炸开、尖耳 | 几点迸裂短线 |
| 思考 | 侧首、一手抬到腮边 | 省略问号，留白给姿态 |
| 开心 | 身体舒展上扬、一短弧笑眼 | 小花、星点 |
| 樱花 | 头顶一朵五瓣樱（线描） | 两三片落瓣 |

## 技术规格
- 只改 seal-studio.html 里 patterns 的 foreground/details 绘制逻辑
- **统一新增"线描模式"**：foreground 改为用红线条勾勒（stroke），而非 fill 实块；保留朱文/白文切换
- 线宽：渲染画布1200px下，主线约 28-36px，配饰线约 18-24px
- 线条圆润：lineCap/lineJoin = round
- 本印（绒球本体朱文方章）是第一优先级，先做这一方并打磨到位，其余依同一语言派生

## 不做什么
- 不加文字（"绒球"篆字留到后续文字印）
- 不改方圆/做旧/导出等已有功能
- 不引入位图/外部字体/emoji进印面
- 不追求一次把八枚全定到完美；本印立住最关键

## 判据（怎么算做好）
- 第一眼像一枚篆刻肖形印，而不是卡通贴纸
- 主体是"红线勾的"，不是"红块填的"
- 没有任何说明性符号（Zzz/?/♥/腮红）
- 印面构图饱满，主体与散点配景有呼应
