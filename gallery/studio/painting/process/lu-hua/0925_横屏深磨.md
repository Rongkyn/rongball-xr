# 芦花 lu-hua · 0925 横屏布局深磨（旧作迭代）

> 性质：**旧作迭代**，非新件。触发自 0924 移动端深磨记录「横屏偏挤（次要，记入后续）」。

## 横屏病理（基线 844x390 实测）
1. 芦苇数量随 `W` 增长（`W/26` 等），横屏 W=844 时数量膨胀，细茎密集成「细棍林」。
2. 株高随 `H` 缩短（`hMin/hMax * H`），H=390 时芦苇只用上画面下半，顶部大片空。
3. 远景簇中心随机定位，实测集中两侧，中间留白仅一根孤杆。

## 修法
- 新增 `LANDSCAPE = W > H`（resize 内设置）。
- 密度改按「有效画幅」`span = min(W, H*2.2)` 计算，宽屏不再翻倍。
- 株高横屏系数 `hBoost=1.32`，穗顶抬入画面；`h` 再以 `min(..., H*0.96)` 封顶。
- 横屏簇数 +2 并均布全宽 `((ci+0.5)/nCluster)*W`，消除中缝孤杆。

## 踩坑（当轮已回流）
- **Array.from 回调参数顺序**：`Array.from({length:n}, (ci)=>...)` 的首参是「元素值」（空槽为
  undefined），index 在**第二参**。误把首参当 index → `((undefined+0.5)/n)*W = NaN` →
  baseX=NaN → `createRadialGradient` 非有限报错。已改为 `(_el, ci)`。
- **ASI 陷阱**：箭头函数表达式换行后以 `+ grand(...)` 起行会被解析为独立语句，箭头返回 undefined。
  最终用块体 `{ const base=...; return base + grand(...); }` 规避。
- 一度怀疑弹簧物理失稳，给 stepReeds 加了子步进 + 有限性兜底（k≈15~21 硬弹簧在 FAST/大扭矩下
  确有边界风险，保留作健壮性加固）；但 NaN 真根因是上述 Array.from index 参数。
