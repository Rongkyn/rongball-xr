## 一句话意图
秋日一池残荷。点一下，落一阵雨——雨珠在枯叶上滚成珠、聚多了叶柄弯腰把水倒进塘里，「咚」一声，涟漪散开；雨会停，池面会平。

## 核心审美判断（本件命门）
残荷的美在**枯的线条与活的圆点**的对比。吴冠中残荷 = 抽象点线面：枯梗是线、莲蓬是点、倒影是破形的面。雨珠是活的高光圆点，在枯赭哑光的叶面上滚——枯与润、线与点、静与动。

锚点三句：
1. **残荷不画全**：几枝错落，大片留白，留白就是池面；
2. **珠在叶上滚，聚多了叶要弯腰**——弯腰倾泻是全场高潮，必须值得等；
3. **雨声比雨形重要**：国画不画雨丝画雨意，「留得残荷听雨声」，声音是本件主体之一，不是配菜。

## 视觉锚点（先看真迹再动笔）
1. **吴冠中《残荷》系列**：极简点线面，枯梗交错如篆书，莲蓬是浓墨点，倒影以破墨横扫——构图与取舍的参照；
2. **荷叶超疏水珠微距**：珠是浑圆透亮的，边缘有深色环线，小珠钉扎不动、大珠滚落合并——「大珠小珠落玉盘」的物理参照；
3. **秋日荷塘照片**：枯赭/焦茶/灰绿的叶，折倒的梗，平静深色的水面——色彩与氛围参照。

## 技术路线
- **荷叶超疏水珠系统**（本件核心创新）：每片盛水叶有局部坐标水珠场——成核（雨落）→ 合并（相碰并珠，质量相加）→ 滚动（质量过钉扎阈值沿叶坡滚向叶心，接触角滞后：小珠钉死、大珠滚）→ 叶心聚洼 → 洼质量过临界 → **叶柄弯垂倾泻**（一串珠从叶缘跌塘）→ 叶柄阻尼弹回。
- **雨事件系统**：tap = 以落点为中心一阵雨（5-9 滴散布）；drag = 雨带随手；雨季启动后环境细雨自持续一段（速率渐衰至 0 = 雨停）。雨滴落叶成珠（嗒）、落塘成涟漪（轻噗）。
- **涟漪**：环形扩散（半径增、线宽与透明度衰减、三重环），倾泻落塘为大涟漪群。
- **残荷生成**：程序化枯枝——梗 = 多段折线+贝塞尔微弯（枯而不直，节点处有节）；叶 = noise 破边圆盘 + 卷边 + 放射枯脉 + 虫蛀洞，半枯盛水叶（赭绿）与全枯垂叶（焦茶）两档；莲蓬 = 倒锥台 + 莲子孔（浓墨点）。倒影 = 垂直镜像压扁 + 低透明度 + 涟漪联动微扰。
- **色彩**：回暖纸白底（苔痕刚冷色石底，交替），枯赭/焦茶/淡墨/一点灰绿，水珠 = 透明体 + 纸白高光 + 深缘线。
- 单文件 HTML 零依赖（声音引 `lib/audio-lib.js` v1.1，系列惯例；头部留 L3 采用记录）。

## 交互
- 轻点 = 一阵雨落向该处；拖动 = 引雨成带；静置 = 雨渐停、珠渐定、涟漪渐平（作品会完成，与苔痕同构的时间感）
- 首次叶弯倾泻 → 淡入李商隐「秋阴不散霜飞晚，留得残荷听雨声」+ 绒球印
- 再来 = 新池（重生成布局）；声音开关；`?fast=1` 加速供 harness

## 声音（磨阶段定配比）
雨打叶「嗒」（带通 noise burst 1.5-3kHz，5-15ms，随机 pan/pitch，密时层叠成沙沙）；雨打塘「噗」（低通 noise + 小 sine 更闷）；倾泻入塘「咕咚」（sine 500→150Hz 快降 + noise 水花）；不做背景乐。实耳校验累积待主人（第五件）。
