## 2. 修复（全部移动端 only，桌面零改动）

1. **诗移左侧净空**：`@media (pointer:coarse), (max-width:560px)` 下 `#poem { right:auto; left:5%; top:12% }`，仍 row-reverse 从右往左成列。
2. **诗加淡纸衬板（保证性净空）**：发现 `#poem::before` radial-gradient 纸色板。
   - 关键判断：荷叶/水珠位置随种子变化（即使 PRNG 确定性，不同 seed 叶缘仍会侵入诗区——m42 实测 darkRatio 0.198），**诗区不能依赖"恰好净空"**，必须有保证性衬底。
   - 衬板 opacity 随 `#poem.show` 一起 4s 淡入，边缘渐变到完全透明不生硬。
3. **hint 单行**：`white-space:nowrap` + 字号 11px + spacing 4px，矮屏再降到 10px。
4. **竖屏纵向拉长因子 VY**：`H > W*1.35` 时纵向分布区间 ×1.28（荷叶、环境雨、auto 雨、倾泻落点距离同步），填充下半空白；横屏/桌面 1.0 不生效。
5. **矮手机（≤700 高，SE 一代）**：诗贴标题下方（top10% gap12% 字号24），hint 抬到 14px 安全区。
6. **顺手修两处**：
   - 矮屏规则里选择器笔误 `#poem .col` → `.line`（该规则此前完全不生效）；
   - auto 验收雨从随机落点改为**瞄准最大盛水叶中心**（spread 收至 0.4 叶宽），消除偶发喂不满叶导致 waitFor 超时的 flake。
