# 芦花 · Lu Hua — 意图

**启动：** 2026-09-13（系列第十二件：流痕→墨韵→绒丝→风铎→墨散→墨洇→听墨→踏雪→天灯→苔痕→残荷→芦花）
**来由：** 残荷（秋塘·雨·水珠物理）收官待审，不碰同题材。时序入秋，开「秋江芦荡」。系列至今做过雨、雪、苔、灯、墨，没碰过「风」作为真正的主体——风铎写的是金属与声音，不是风场本身；也没有「风载粒子」的散逸行为。本件补这两块。

**启动门三问：** 🏷️类型=🎨画房（作品，不是工具）｜🎭角色=Maker 作画 + Checker 独立验收分离（CDP harness + vision）｜🎯判据=画好不好看、秋风芦荡的感觉对不对。峰值瞬间截图给不知道机制的人看，说得出「风把芦花吹散了」才算成立；风住要有「松一口气」的感觉。

## 一句话意图
秋日江滩一片芦苇。轻点起一阵秋风——风过芦荡，所有花穗集体低头成浪，白絮从穗尖被撕起，飘满江天；风一阵比一阵弱，穗子晃着直回来，飞絮落定。会完成的一场风。

## 核心审美判断（本件命门）
芦花的美在**集体的浪**与**个体的散**。不是几十根草各自摇，是风像手一样拂过芦荡、有波前有迟滞；高潮是白絮被撕离穗尖的一瞬——蓬与散、聚与逸、重与轻。

锚点三句：
1. **芦荡是集体不是个体**：弯腰方向统一、有波前传过，像吴镇《芦花寒雁图》前景芦叶「姿态统一向侧方倾斜」的动态版；
2. **穗是蓬松的白不是线**：逆光芦花是透光白绒羽+基部暖棕脉络，画成亮棕色棒棒就是失败；
3. **留白即江面**：水不画满，淡墨横线几丝波纹，大片纸白，与吴镇平远水法一致。

## 视觉锚点（先看真迹再动笔）
1. **吴镇《芦花寒雁图》**（元）：前景浓墨劲挺芦叶统一倾偃，水面极淡墨线波纹+大片留白，平远构图、洲渚层层淡去——构图与水法参照；
2. **边寿民芦雁册**（清，苇间居士）：芦穗蓬松赭白、墨色浓淡区分远近、风势明确——穗的笔法参照；
3. **芦花逆光微距摄影**：白绒羽透光、边缘亮白轮廓、基部暖棕褐丝缕、集体同向弯垂——蓬松材质与风态参照；
4. **风吹芦苇荡视频/照片**：波前横向扫过、茎秆弹性回摆、穗部相位滞后于茎（鞭梢效应）——集体运动参照。

## 技术路线
- **风场（本件核心创新1）**：风不是每株独立随机，是一个跨空间跨时间的场。环境风 = 基础微风（低频 sin+noise）；阵风 gust 有生命周期（起—峰—衰），强度包络 × 沿水平方向传播的波前（wind(x,t)=gustEnv(t)·profile(x-v·t)），近处茎先弯、波前过后依次回正，形成扫过的浪。
- **茎秆弹性模型**：每株芦苇 = 基部固定的悬臂，弯曲角由「风力矩 vs 回弹弹簧+阻尼」积分（ω' 形式的扭摆），茎越高越柔（k∝1/h² 感）；**穗相位滞后**：穗尖位置用弯曲角的低通+过冲，鞭梢效应。
- **蓬松芦花渲染（核心创新2）**：穗 = 多根次级穗轴（从穗轴发出的细丝簇）+ 每根轴上大量极短线毛粒子。绒毛沿主轴方向分布，受弯时整体跟随；用低对比暖白底上的「深丝缕+白绒光」双层画法，不用实心填充。近景穗大、绒毛可读；中远景穗退化成淡赭白小笔触。
- **散絮系统（高潮·核心创新3）**：阵风过阈值时，迎风侧穗尖撕出飞絮。飞絮 = 2-3 根细丝+小绒团的复合粒子，沿风场平流+自身沉浮（终端速度近零，缓慢正弦飘摆），粒子数随风强；风衰后渐落出画/淡出。**穗的蓬松度随散絮量略减**（被撕薄了）——因果可见。
- **江景层次**：近景芦荡（画面下 1/2~2/3，浓墨茎+可读绒穗）；中景洲渚淡墨横点；远景 1-2 道极淡岸线+雾；水面留白 + 2-3 组淡墨横线波纹（风大时波纹略密略长）；天是纸白，不画云。
- **生命感小物**：风里可有 2-3 只远鸟/雁（极简墨线 V），被风势带得略倾——点题《诗经·秦风·蒹葭》与吴镇寒雁，但不抢戏（v1 可省，磨阶段定）。
- **色彩**：暖纸白底（与苔痕冷石底交替、与残荷同暖调但区分：残荷是赭褐枯塘，芦花是浅金+白+青灰远水）；茎秆枯赭绿/焦茶，穗=米白绒+基部暖棕丝，远水极淡青灰。
- 单文件 HTML，零依赖（声音引 `lib/audio-lib.js` v1.1，系列惯例；头部留采用记录）。

## 交互
- 轻点 = 该位置起一阵秋风（阵风向一个主导方向，左右随机但一程内一致）；
- 拖动 = 持续的风带（风向随手移动方向，风速随手速）；
- 静置 = 风一阵比一阵弱、穗晃着回正、飞絮落定（作品会完成，与残荷/苔痕同构的时间感）；
- 首次散絮飞满 → 淡入《诗经·秦风·蒹葭》「蒹葭苍苍，白露为霜。所谓伊人，在水一方」+ 绒球印；
- 再来 = 新芦荡（重生成布局）；声音开关；`?fast=1` 加速供 harness。

## 声音（磨阶段定配比）
风穿芦荡「沙沙」（bandpass-filtered noise，中心频率随风速走、密时带芦秆细碎噼啪）；阵风强度包络同步到滤波与增益；穗尖散絮几乎无声（一声极轻的「嘶」气声，极克制）；五声阶轻磬一声（strikeBell，风住时，留白）；雁叫不做（太具象，破静）。实耳校验累积待主人（第六件）。

## 预期 contribution
1. **作品本身**（第十二件：首件风为主体、首件集体波场、首件风载散逸粒子、首件秋江芦荡题材）。
2. **传播型阵风场模型**：包络×行波波前，让「风拂过」成为可读事件而非噪声抖动——可回流 simulation-atlas 作「集体场行为」case，与残荷「单点液体珠」互补。
3. **蓬松绒面画法**：丝缕+绒光双层、无实心填充，穗部滞后鞭梢——系列材质库新砖（残荷贡献了枯荷形态库，芦花贡献蓬松绒面库）。
4. **高潮可见性判据的二次压测**：残荷立的判据（不知道机制的人看得出发生了什么）在「散逸」类事件上是否成立——水是聚（看得见落点），絮是散（飘走就没了），阅读层设计不同。
