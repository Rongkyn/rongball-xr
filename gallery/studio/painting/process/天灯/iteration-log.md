# 天灯 · iteration-log

> v1–v4 按作品 notes（`gallery/works/tian-deng-notes.md`）与冻结闸口 1004 结果回填。

## v1 · 2026-08-30 · 一夜的河
- 深蓝夜空渐变 + 两层远山剪影 + 芦苇 + 水面横波，纯场景先立氛围。
- 判定：环境对了，灯还不存在。

## v2 · 2026-08-30 · 一盏能折的灯
- 竹骨架 + 灯纸折纸感：拖拽折边，折痕逐步生成，折完进入点灯。
- 坑：折纸判定用绝对坐标，窗口一变全错位。→ 全部归一化到画布比例坐标。
- 判定：动作成立，但灯是冷的。

## v3 · 2026-08-30 · 点火
- 灯芯火苗程序化（多层噪声+呼吸缩放），暖光映在灯纸上跳动，水面倒影碎成横向光斑。
- 音频：火苗低频噼声 + 环境风声，点灯瞬间轻「噗」。
- 坑：火光用加法混合叠太多层，移动端发烫掉帧。→ 暖光压到两层、火苗单离屏缓存。
- 判定：灯活了，还没有被放走。

## v4 · 2026-08-31 · 放灯
- 上推手势放灯：灯离手 → 水面倒影随距离变淡变碎 → 灯变小渐远，风轻微改变航向。
- 坑：第一版灯匀速直线飘走，像贴图平移。→ 加横向正弦漂移 + 倒影非线性衰减。
- 坑：反复进出导致音频节点泄漏。→ 单实例生命周期，离开段落先收声再清理。
- 判定：四段式仪式完整，转候选池等冻结。
