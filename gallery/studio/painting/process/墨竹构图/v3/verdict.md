## 裁定：v3 不予上线

| 版本 | 双轨/亲验分数 | 关键问题 |
|------|--------------|---------|
| v1 | 大众6 / 专家4.7 | 左挤右空、截图带UI、枝不穿插 |
| v2 | 5.2 / 4.25 | UI已清✅；左沉右空原封不动；lean微调视觉无效 |
| v3 | 亲验约5.0（未达7分线） | 左空缓解✅；但5竿排队、竿直如杆、叶聚顶部 |

**裁定依据：**
1. v3 亲验：横向展开有效，但根点 y 几乎同高（0.82–0.89），5 株仍呈一条松散横线；主竹 lean +0.35 在 1600px 画幅下肉眼几乎不察，竿身笔直；枝叶全聚梢部，下半截光杆。
2. v2 双轨已明确预判：画房把横向展开这最后一招用完，上限约 5.0–5.5，叶簇死墨、枝不穿插、竿身平涂是工坊算法缺陷，参数绕不过去。
3. v3 实测与该预判一致。

**处置：**
- v3 作为「画房构图最优参考」存档，不进画廊上线序列。
- 画房本轮「磨」到此为止，不再追加 v4（继续调参是在工坊缺陷上做无用功，违反单变量ROI原则）。
- 工坊缺陷清单已在 `feedback/墨竹构图-v1-feedback.md` 立项，本轮新增 3 条（见复盘）。
- 墨竹作品上线须等工坊完成「叶片密度衰减 + 跨株枝条牵引 + 竿身笔触迁移」三项改造后，重开画房循环。

## 画房能力边界（本轮实证）

画房（调种植参数：x/y/seed/hMul/stalkCount/lean）**能解决**：
- 画面重心、左右平衡、远近层次、主宾排布、疏密大关系

画房**不能解决**（必须工坊改源码）：
- 竿身欹侧笔势（lean 对最终竿形影响被算法抹平）
- 出枝节奏（对称/等概率，种多近都不交叉）
- 叶簇死墨暗块（无碰撞衰减/透叠）
- 节距均匀、枝叶分布偏顶部
- 竿身笔触飞白（drawBambooStalk 未迁 V5）

这个边界是本轮最重要的资产：以后竹子类问题先判路由，别再让画房白调参。
