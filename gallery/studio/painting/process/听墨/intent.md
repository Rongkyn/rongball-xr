# 听墨 · 研（创作意图）— 2026-08-27

## 一句话意图
一滴墨落纸，**听见**它洇开的全过程。声音不是配乐，是墨洇模拟过程的声化（sonification）——水锋推到哪，耳语就响到哪；水尽墨定，一声低铃收印。

## 基底与增量
- 基底：墨洇 v10 引擎（2026-08-26 交付，7.2 分过门槛，四场纯扩散+毛细模型），原文件不动，复制为 ting-mo.html 增量开发
- 今日增量只有一件事：**声音**。视觉不改（除页脚声音开关）

## 声音叙事弧（对应作品状态机）
| 状态/事件 | 声音 | 合成思路 |
|---|---|---|
| 清纸（双击） | 研墨刮擦 ~0.9s | 噪声+带通扫频+慢LFO幅度（转圈研磨感） |
| 落墨（点按） | 软噗 thump | sine 150→90Hz 俯冲 120ms + 500Hz 噪声 burst 30ms，落点 x→pan，墨团大小→音量 |
| 行笔（拖扫） | 纸摩擦颗粒 | 带通噪声 1200-2500Hz 短粒 40-80ms，笔速→增益，60ms 限流 |
| 洇散中（持续） | 锋线耳语 | 循环噪声→bandpass(400-900Hz)→gain(0~0.05)，由模拟锋线活动度驱动 |
| 水尽墨定 | 低铃一声 | RongAudio.strikeBell(196, 0.32)，与印章亮起同步 |

## 审美判据（锚点）
1. **声音从属于画面**：全部音量克制，像从纸里透出而非喇叭放出；master 降到 0.55
2. **声音必须由模拟状态驱动**，不是随机氛围乐——锋线活动度（tide 累计）是唯一耳语输入
3. **墨韵判据姊妹条**：墨韵是"视觉消退必须远快于音频延音"；听墨反过来——**环境声起伏必须慢于视觉事件**（setTargetAtTime τ≈0.4s 平滑，禁止逐帧抖动）
4. 第一眼/第一耳不需要解释：不听说明也能感到"墨在纸上活着"

## 工具选择
- 作品内先行开发声音（ting-mo.html inline），验证稳定后按 lib 惯例**提取沉淀**为 audio-lib.js v1.1 第三资产（dogfooding 双环：用→发现→入库）
- CDP 验证：chrome `--autoplay-policy=no-user-gesture-required`（lib README 验证约束），探针 `window.__snd` 计数五类声音事件 + AC state

## 风险与克制
- Web Audio 节点泄漏：颗粒/噗声都是短生命周期节点，stop 后自动回收；耳语用常驻单节点只调参数
- 墨洇原交互/渲染/物理**零改动**，声音只读状态（frontAct/totalWater/事件钩子），最坏情况静音不影响画
