## v1 能力

- 输入一句话 → FNV-1a hash + mulberry32 确定性成画（同句同卷像素一致）
- 11 个主题（月/雨/雪/江/舟/花/竹/秋/鸟/云/山），加权关键词诗性映射，ORDER 同分裁决 + 山兜底
- 三层 fBm 山脊、宣纸纤维、雾、皴笔、雪顶留白、水纹、渔舟（含倒影）、竹丛、花鸟点景、雨丝
- 竖排题字 + 落款 + 程序朱印（印文取主题意象字）
- 换一卷（变体）、题我的原句、存 PNG（`yijuhua_<名>_v<n>.png`）

## 验收（acc1023_p01.js，56 断言）

双档 CDP（mobile 390×844 / desktop 1280×720），9 个验收面 A–I：
主题映射 11 例、成画闭环、确定性（hash/seed）、分区像素、题原句标注、
toDataURL PNG 拦截、零外链、无横向溢出、连绘性能、零真实 JS 错误。
当前 **56/56 PASS**（`acc1023_p01_result.json`）；移动单次渲染 22ms 级。

## 三轮迭代史（2026-10-23）

1. 一轮 38/56：
   - 测试脚本 trustedClick 不传坐标 → 插值 NaN 点到页面原点（假阴性）→ 新增 centerClick（scrollIntoView+rect 中心）
   - 主题泛词压制（"晚/月"）→ keys 改 [词,权重] 对 + 特异度 ORDER；用例换完整诗句上下文
   - 近山黑块、雾横条、皴如丝、题字首行错位 → 层位/渐隐/短横皴/textBaseline 修复
2. 二轮 54/56：
   - 1280×720 矮视口按钮被高画布顶出视口，CDP 点击静默丢失 → centerClick 先 scrollIntoView({block:'center'})
   - 月题纸底整幅压暗 + nightWash 灰染（4 个 /tmp 探针逐级定位）→ 纸底不分昼夜统一暖色，夜意降为月周冷晕
3. 三轮 56/56 后目检未过自我满意闸（月隐身/水平色带/近山实块/雪顶如描边/舟不可见/印文取句首字），美学二轮：
   - 山体改「实色山形 + destination-out 山脚渐隐蒙版 + 临时层 destination-in 裁剪再贴回」（学自 works/mountain-dwelling.html；**destination-in 不能直接作用主画布，会裁掉蒙版外纸底**）
   - 月：象牙白面 + 淡金晕 + 细金边；雪顶改峰顶肩坡留白块；水先压云水亮带托舟；舟放大加倒影；印文改主题意象字；花点约束浅色坡脚；远鸟放大
   - 山脊加高频碎峰增棱；皴笔加重加密并随坡深入；近山脊用多道由粗到细焦墨线（替代会穿出尖牙黑块的世界坐标渐隐内带）
   - 终轮 56/56 + 12 主题目检通过
