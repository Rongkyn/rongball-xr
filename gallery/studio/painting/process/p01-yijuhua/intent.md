# P01 一句话水墨 · 立项纸

> 作品池 ID：P01｜出口：产品（首发小红书 Builder Hub 小工具）+ 内容 + 简历叙事
> 立项：2026-10-23 创作时间（补 10-21 欠账：首发阵地改定后立项纸优先于其他件）
> 状态：立项 → v1 内测原型（待主人圈选，圈选前不上架/不对外发布）

## 一句话定义

输入一句话（心情 / 名字 / 诗句），秒出一幅带题字与朱印的程序化水墨壁纸，可存图分享。纯前端、零外部 API、零依赖，单文件即可挂进小红书 Builder Hub 沙箱。

## 为谁解决什么

- **用户**：小红书国风 / 壁纸 / 取名 / 文案话题下的普通用户，想要一张「有自己名字 / 自己此刻心境」的高级东方感图，但不会画、用西式 AI 出图又全是油画质感。
- **爽感链路（30 秒看懂）**：写一句话 → 点「成画」→ 得到一幅构图、题诗、朱印俱全、每次不同的水墨壁纸 → 存图发笔记 / 换头像 / 发朋友圈。
- **差异点**：同话题现有产品多为西式滤镜或真模型出图（慢、风格不可控、要加载）；我们是 21 件水墨作品验证过的程序化渲染，秒出、零成本、断网可用、风格稳定在东方水墨。

## 平台约束（2026-10 核实，决定 v1 形态）

小红书小工具 = Builder Hub 上传、挂载笔记下方、App 内即点即用；**沙箱纯前端：禁外部 API、禁服务器 / 数据库**。
→ v1 必须单文件自包含：不调模型，不引外网字体 / 图 / 脚本；语义理解走本地关键词 → 主题模板映射（程序化生成 ≠ AI API，叙事仍然成立：「确定性的诗性映射 + 程序化独一构图」）。

## v1 最小版本范围（本次 1023 原型）

- 输入框（心情 / 名字 / 诗句）+ 「成画」+「换一卷」（同句变体）
- 1080×1440 竖幅壁纸画布，移动端 390 优先、桌面可看
- 程序化画面：宣纸底纹 + FBM 多层山脊 + 云雾 + 朱印；主题识别：月/夜、雨、雪、江/水、舟、花/春、竹、秋、鸟、山，各配公认诗句题字
- 题字：竖排诗句（右起）+ 朱砂方印（印文取输入首字，缺省「墨」）；「题我的原句」开关 = 直接竖排用户原句
- 存图：canvas → PNG 下载
- 同句 + 同变体确定性（种子 = 文本 hash + 变体号），可复现、可做分享锚点
- 零外链、零依赖、零 JS 错误；生成耗时移动模拟 < 1s

## 不做（v1 边界，防蔓延）

- 不调任何模型 / API；不做账号体系、云端图库、社区 feed
- 不做付费 / 小黄车；不做矩阵号
- 动画只保留极轻的入场（或 v1 纯静帧），不做可交互山水
- 印章 v1 程序化方印，不做复杂篆体排布（印章图案资产留 v2）
- 题诗库 v1 为十主题各 1 句公认名句，不做诗词生成

## 成功指标（第一款不背收入 KPI）

- 主指标：挂载后真实非亲友使用次数、生成 → 存图转化率
- 辅助：挂载笔记自然赞藏；「求 XX 主题」评论数（主题库扩张依据）
- 简历口径：她主导（圈选方向 + 发布）+ 已上线 + 有真实用户数据；可讲「官方国风活动窗口 + 程序化生成技术选型 + 零成本沙箱约束下的产品闭环」

## 复用与被复用

- 复用：21 件水墨作品的山脊 / 云雾 / 印章 / 竖排题字技法经验（本次按小工具场景新写紧凑实现，未直接搬耦合代码）
- 回流：渲染原语（FBM 山脊 / 竖排题字器 / 程序印章 / 主题映射）登记 POOL candidate，P08 长卷寻灵与 P03 inkwash-engine 开源件下次触碰时评估提取
- 研究线接口：AI 生成实验室（谢赫六法提示词）产出的构图 / 审美规则未来作为主题模板的审美升级弹药，v1 先手工模板

## 风险与对策

| 风险 | 对策 |
|---|---|
| 程序化画质打不过真模型出图 | 打「构图+题字+印章」的完整文人画气质，不拼照片感；CDP 截图逐主题目检迭代到过关再给主人看 |
| 主题误匹配（空山新雨后含「山」又含「雨」） | 关键词加权打分，特异词（雨/雪/月/舟…）优先于泛词（山/夜），验收固化 |
| Builder Hub 沙箱实际限制与公开资料有出入 | v1 零外链单文件已是最严约束；上传环节主人本人到场，实测再适配 |
| 题诗版权 | 只用公认古典名句（作者殁世千年以上），UI 不冒认为自作 |
