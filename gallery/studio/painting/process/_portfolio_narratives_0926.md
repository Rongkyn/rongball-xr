## 1. 墨园 Ink Garden｜体系最完整的生成艺术件

- **背景**：生成艺术常陷入两种极端：纯随机图像只产生一次性的「好看」，预设动画则每一次观看都相同。我想做一座真正「生成」的园子：每次入园都不一样，但草木的生长遵循可解释的规则。作品也承担实验目的：验证递归分形与种子随机能否在浏览器里支撑一个可长期游玩的生态场景。
- **我的角色**：个人项目，独立完成设计与全部代码；作品经历 v1→v12 再到 0919/0920 性能与移动端深磨的完整迭代。
- **做法**：
  - 用递归分形生成竹、松、柳、梅、兰、枯木六类植物，枝叶逐节抽长；每株由种子驱动，同一种子复现同一植株，不同种子没有两棵相同。
  - 设计完整交互循环：点击落点生長，右键/长按移除单株，亦可随缘成林、一键清园；枝叶受风场影响轻摆，偶有落叶飘零。
  - 高密度场景下用运行时画像加滑动窗口 FPS 监控做自适应降档：帧率低于阈值时依次关闭落叶、减少风动刷新、降低细节，帧率回升后经迟滞防抖再恢复，避免画面跳变；初始档位按设备内存、CPU 核心与移动端信号确定。
- **成果**：
  - 桌面 11/11、移动 15/15 CDP 验收通过（0919/0920）；后续 0922 修复整屏清闪（resize 防抖+渲染增量），0924 接入共享防抖库。
  - 形成跨作品复用的两个能力候选：自适应性能降档器、笔刷引擎；体量约 203KB（gzip 约 62KB），无外部资源依赖，单文件离线可开。
  - 待主人手机实机确认降档平滑度与印章位置，认可后可圈选冻结。

## 2. 残荷 Can He｜物理叙事最完整的强候选

- **背景**：秋日残荷的美在枯的线条与活的圆点的对比（吴冠中点线面）。我想做一场「会完成」的雨：雨珠在枯叶上滚成珠、聚多了叶柄弯腰、一串水泻进塘里，雨会停、池面会平。命门判断：弯腰倾泻是全场高潮，必须值得等；雨声是作品主体之一，不是背景音。
- **我的角色**：个人项目，独立完成；经历 v1 视觉定版 → v2 物理闭环 → v3/v4 构图与泻流可读性重写（0910–0912）→ 0921 移动端深磨的多版迭代，证据链完整。
- **做法**：
  - 自建超疏水珠模型：成核→合并（质量相加）→滚动（接触角滞后：小珠钉扎、大珠滚向叶心）→叶心聚洼→过临界弯茎倾泻→阻尼弹回。
  - 雨生命周期状态机：tap 一阵雨 / drag 雨带 / 环境雨渐衰自停；弯茎由 bend 参数驱动叶心位移与前倾，弹簧回位。
  - 泻流可读性经两版重写：从「克制到读不出」到「光剑」的两次失败后，定为四层结构水带（极淡外缘晕、暖灰青主体上实下虚、小比例中央高光、沿线流动水团），水带、泻落珠、涟漪共用物理锚点保证击水对齐。
  - 0921 移动端：诗移左侧净空并加保证性纸衬板（可读性不依赖随机构图净空）、竖屏纵向分布因子、hint 单行、矮手机专项。
- **成果**：
  - 移动 3 种子+桌面回归 29/29 CDP PASS（两跑稳定），390×667/844×390 边界入屏零错误。
  - 沉淀跨件原则：保证性浮层净空、竖屏 VY 因子、验收确定性落点；避坑#17（file:// 未编码中文路径致静默导航失败）回流 harness。
  - 待主人手机/Pico 实机确认触摸手感与诗衬板观感，认可后可圈选冻结。

## 3. 听墨 Ting Mo｜声化双环与库 dogfood 故事

- **背景**：墨洇（系列第六件，自评 7.2）只让墨被看见。我提出一个问题：一滴墨洇开的过程能否被「听见」，而且声音必须从模拟状态生长、不是配乐？目标是让声化成为物理过程的诚实映射。
- **我的角色**：个人项目，独立完成声音设计与合成；作品同时作为共享音频库 audio-lib 的首个真实 dogfood 场景，形成「作品暴露库缺口→修复 v1.1→作品受益」的双环。
- **做法**：
  - 五声对五态：落墨软噗（频率俯冲+噪声点，大小定音量音高、落点定声像）、行笔摩擦颗粒（带通噪声随笔速）、洇散锋线耳语、清纸研墨刮擦、墨定低铃（与印章亮起同帧）。
  - 锋线活动度 frontAcc 由每帧模拟细胞 tide 值累计得出，标定曲线呈现两相衰减（11.6k@3s→18.1k 峰值@25s→0@≈400s 全干），归一化后驱动耳语；双层平滑（0.85 指数平滑 + setTargetAtTime τ0.4s）保证环境声起伏永远慢于视觉事件。
  - 零侵入嫁接：物理、渲染、交互零改动，声音层只读状态加事件钩子；库缺失或自动播放策略限制时静默降级并提示「声·待启」。
  - 0918 移动端深磨：响应式方画框入屏、修颗粒声回归（lastGrain 未声明致真机从未响的 P0）、长按清纸手势。
- **成果**：
  - 双端 13 项 CDP 断言 PASS（0918）；五类声音事件探针、音频上下文状态机、干燥 e2e（单滴≈400s 全干铃响 1 次）全验证，零 JS 错误。
  - dogfood 促成 audio-lib v1.0→v1.1（out() 总线出声口）；审美纪律成文：音量从属预算+环境声慢于视觉事件。
  - 诚实扣分项：音色未经实耳校验（headless 只验参数与触发），研墨 LFO 转圈感物理性最弱；待主人实耳与圈选冻结。

## 4. 芦花 Lu Hua｜风的行波与诗境时序

- **背景**：「蒹葭苍苍，白露为霜。所谓伊人，在水一方。」我想把《秦风·蒹葭》的时序变成可玩的机制：风像手一样拂过芦荡，芦花低头、白絮被撕散飘满江天，风住穗回。参照吴镇《芦花寒雁图》的留白与寒雁母题。
- **我的角色**：个人项目，独立完成；v0913 首版后经 0924 移动端、0925 横屏布局两轮深磨。
- **做法**：
  - 阵风=生命周期包络×行波波前：风从落点起、波前以固定速度传播，茎秆在波前经过时受力、波后回正，不是全场同时弯；长按拖动留下持续风。
  - 每株芦苇是弹簧悬臂（按株高取劲度系数），分段积分且局部倾角随高度放大（根刚梢柔）；风力过阈值时白絮从穗部被「撕」出，平流随风、正弦沉浮。
  - 诗境时序：一阵风凑够 18（快）/26（真实）絮，竖排诗句淡入；风大时寒雁两笔顺风掠过，风住一声玉磬收束。
  - 关键审美修正：等距 herringbone 丝缕画成麦穗而非芦花，改为随机碎绒加穗部独立随机源（消除逐帧闪烁）；基部长草改簇生草须系统，拒绝对称装饰图案。
  - 0925 横屏：引入横屏布局因子，密度按有效画幅、株高补偿、簇均布全宽。
- **成果**：
  - 三种子快进峰值穗弯 18°/19°/29°（优雅不翻折），风住 2s 回正；真实节奏 8.5s 空中 180 朵飞絮、诗已显；0925 五场景 CDP 10/10 PASS。
  - 横屏因子、硬弹簧稳定域加固入 POOL 候选。
  - 待主人实机旋转看横竖观感，认可后可冻结。

## 5. 秋虫 Qiu Chong｜寻声定位与空间声像

- **背景**：入夜草丛里虫声远近错落。我想做一个反向的捉迷藏：不靠眼睛找目标，而是听声辨位，点击鸣声来处，草叶轻分、露出鸣虫；寻得几只后夜色转凉、诗境浮现。
- **我的角色**：个人项目，独立完成；0924 修 P0 同步死循环并接入防抖，0925 横屏深磨。
- **做法**：
  - 每只鸣虫的鸣声在双耳间按实际位置做声像（pan）与远近处理；草丛程序化生成并按触摸方向轻分。
  - P0 修复：页面解析早期 innerWidth/Height=0 时，drawGround 的 `x += W/14` 步长为 0 陷入同步死循环（readyState 永停 loading）；加零尺寸守卫并把循环步长改为 `Math.max(1,…)`。
  - 0925 横屏：GROUND 下移、草高补偿、resize 末尾重建场景（旋转后位置不残留旧朝向）。
- **成果**：
  - 0925 五场景 CDP 10/10 PASS，无横向溢出零错误。
  - 「resize 必须重建场景」「除法步长零尺寸死循环」两条经验入 POOL/harness。
  - 待主人实机确认（戴耳机体验声像），认可后可冻结。

## 6. 桂雨 Gui Yu｜中秋件·弹簧摇枝与粒子预算

- **背景**：中秋窗口需要一件可发布的应景作品。月下江南庭院一棵斜生老桂：点拖树冠，弹簧摇枝、金桂如雨；点天空，一阵风从全冠撕下一层花；花落地面慢慢积成碎金。
- **我的角色**：个人项目，独立完成；0922 移动端深磨（当周已获主会话批准作节令件）。
- **做法**：

  - 0922：印章/hint 分层、小屏 hint 入屏、resize 防抖；声音走自有音频库。
- **成果**：
  - 桂雨/月波双件 40 项 CDP 断言全 PASS（各 20 项）。
  - 待主人手机实机确认；中秋窗口（9/25）已过，是否仍作发布件待主人定。

## 7. 月波 Yue Bo｜中秋件·水波模拟与光影愈合

- **背景**：满月映江，波光是一条随水晃动的亮路。作品核心隐喻是「碎与圆」：点击或拖动水面，月影碎成千万片金鳞，风停水静后又缓缓合拢。
- **我的角色**：个人项目，独立完成；0922 移动端深磨。
- **做法**：水波网格驱动反光变形，交互扰动叠加后按阻尼恢复；月影以金鳞碎片渲染，愈合过程渐进不跳变；移动端同桂雨做印章/hint 分层与防抖。
- **成果**：40 项 CDP 断言双件全 PASS；待主人手机实机确认，发布与否同桂雨待主人定。
