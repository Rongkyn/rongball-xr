## 过程中暴露的 3 处「断言口径」问题（均非作品缺陷）
1. **ting-mo backing 是 N=320，不是 704**。#ink 是扩散模拟网格（320×320 固定物理坐标），
   704 是宣纸纹理层 #paper。固定坐标方画框 CSS 缩放显示，不能按 css×dpr 判 backing。
2. **can-he 手势后固定延时读镜像不可靠**：镜像每 10 帧刷一次（立即读拿到旧帧），
   fast 下雨 rainLevel 按 dt×3 快速衰减（τ≈1.4s，读太晚归 0）。→ 已提为 harness 避坑#21，
   正确口径是手势后 waitFor「镜像字段离开手势前值」，~1200ms 窗口轮询。
3. **mo-yin 清纸无按钮**：桌面双击、移动端长按 800ms（作品 hint 明示）。清纸判据只认 tw（总水量）归零；
   宣纸层有固定底纹墨点，墨色像素判据会误报，tw 是权威信号。
