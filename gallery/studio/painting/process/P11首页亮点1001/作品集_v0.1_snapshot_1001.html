Spatial Studio: Soundscape(VR)

VR / 空间交互 · 硕士毕设

一个 VR 空间内的 AI 辅助空间音频创作工具：让没有专业声音制作经验的人，置身声音空间中，用身体行动直接组织、试听和调整声音。

VR 空间声景创作原型

硕士毕业项目 · 独立完成研究、设计、开发与论文 ｜ Unity 6.3 + Pico
图片占位：毕设 Demo 视频 / 头显内创作场景全景
（待主人回国后 Pico 投屏录屏，剪 60–90s）
图片占位：声音对象在三维空间中的可视化场景
图片占位：手柄抓取/放置声源的交互画面
背景 · 为什么做

有声音创作意愿的人往往卡在第一步：在传统 DAW 工作流里，必须先把"让水声退到远处、让鸟在树上鸣叫"这样的想法翻译成轨道、声像和参数，才能听到结果。学习工具和格式转换占用了本可用于创作的注意力，许多声音想法因此停在未实现状态。

我的角色

个人硕士毕设，独立完成研究问题定义、VR 原型设计与开发、参与者创作任务设计与论文写作；论文 7 章已定稿。

做法 · 怎么做的
  • 基于 Unity 6.3 + XR Interaction Toolkit + Pico SDK，在 Pico 头显上构建可实际体验的 VR 创作原型，全程 AI 辅助编码（Cursor），独立完成调试与架构重构；
  • 工程上搭建 25 个 Assembly Definition 的分层模块化架构（Domain / Interaction / Presentation / Flow / Services），含 EditMode / PlayMode 测试；
  • 核心设计：声音材料以可见、可抓取的场景对象进入三维空间——空间化建立声音的位置/方向/距离关系，可视化呈现场景与声源，对象化把声音组织为可组合的创作单元，直接操作 + 即时试听连成完整创作循环；
  • 设计有界的参与者创作任务，结合参与者表述、过程观察与创作结果做质性分析。（测试人数与关键发现：待补）
成果
  • 完成可在 Pico 设备上运行体验的 VR 空间音频创作原型，并形成"降低创作门槛"的设计机制论证；
  • 研究焦点落在创作早期阶段：VR 作为形成、尝试和修改空间声景的创作环境，帮助创作者在不确定要做什么时就能动手尝试，在不熟悉怎么实现时就能听到结果。
