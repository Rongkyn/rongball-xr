# 墨洇 — 迭代日志（墨散重启·纯扩散毛细模型）

## 2026-08-26（v1–v10，当日闭环）

**结果：Checker 自评 7.2/10（大众7.5/专家7），过门槛，入 gallery/works/mo-yin.html。**
**核心验证：纯扩散+毛细模型能说出 RD 说不出的水墨晕染语言（昨日方向假设证实）。**

### 模型（四场，抛弃反应项）
- W 水场：9点 Laplacian 纯扩散（D=0.38）+ 蒸发 2.8e-5（沿纤维通道差异调制）
- P 悬浮色素：毛细挂墨（迁移率 ramp 于 W∈[0.008,0.09]）+ **平流 ADVEC 随水流（咖啡环机制，水量闸门 ADVEC_W=0.45 只在薄水发力）**
- S 沉积：基础吸附×纤维 + 锋线窄带钉线（峰值 w≈0.05 抛物带）+ 水干急速挂墨
- F/F2 纸纤维：低频值噪声帘纹 + 高频锐化纤维通道（调制扩散/蒸发/沉积三端）

### 关键轮次
- v1–v2：合成事件 setPointerCapture 报错修复（try/catch + lastP 守卫）
- v3：斑点不扩散——水量预算过少。**水量标定是扩散表演的第一参数**：峰值需在表演全程 > 锋线阈值
- v4：水量+EVAP 修正后出宽淡晕，但面包圈（初始落墨边缘 tide 发力+内部色素外流失）
- v5：tide 闸改薄水窄带 + 落墨三成瞬时入纸锚定焦芯 → 焦芯饱满；淡墨改暖灰
- v6：加平流 ADVEC 0.6 无闸门 → 抽空墨芯、笔画出双轨线（回归面包圈）
- v7：平流加水量闸门 ADVEC_W=0.45（厚水处无平流）→ 墨芯恢复 + 外线初现
- v8：锋线窄带钉线（w≈0.05 峰值）+ F2 锐化成纤维通道 → 外缘线清晰、内部横丝
- v9：蒸发沿纤维通道差异（前锋破形的直接杠杆：前锋处 LB 小，调制扩散率不如调制蒸发）→ 边缘毛刺
- v10：横丝去方向性（防印刷感）+ 前锋扰动 0.9 → 定格

### Contribution 声明
1. **方向证实（最重要）**：纯扩散+毛细模型说出水墨晕染语言。RD 版 23 轮调色救不回，新模型 10 轮达标——**模型选语言，调色救不了模型**
2. **咖啡环平流须配水量闸门**：solute advection 在厚水处会抽空墨芯（v6 教训），物理上蒸发驱动流只在前沿显著，ADVEC_W 闸门是必要项
3. **前锋破形的第一杠杆是蒸发端，不是扩散端**：前锋处 Laplacian 小，调制扩散率绝对量小；蒸发直接决定前锋存活/钉扎位置。与昨日 RD 判据"扩散端扰动危险"互补：纯扩散系统三端扰动全部安全（无条件稳定，无波前失稳）
4. **焦芯锚定**：落墨即按比例瞬时入纸（三成），等效真实纸面瞬时吸墨，防面包圈的最简机制
5. **水量标定公式**：水峰值 p(t)=M/(2πσ²)·e^(-EVAP·t) 需全程 > 锋线阈值 θ，否则表演中途"断水"停滞（v3 教训）；扩散半径上限 R≈σ·√(2ln(p/θ))
6. **可复用资产**：mo-yin.html 四场晕染引擎（12KB 零依赖）——水/色素/沉积/纤维场结构可直接服务后续水墨小品
