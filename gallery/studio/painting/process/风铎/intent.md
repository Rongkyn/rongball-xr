# 风铎 · Wind Bells — 研（intent）

**日期：** 2026-08-22
**类型：** 交互式音画小品（系列第四件：流痕→墨韵→绒丝→风铎）

## 一句话意图

夜檐下一排铜风铃，风来时铃舌撞管、疏密随心——大部分时间是静的，风过的瞬间满檐清响。

## 视觉锚点

- 暗靛蓝夜空 + 暖铜/金铜铃管，冷暖对比（沿用绒丝的暗色底+暖主体判据）
- 顶部一道檐木横梁，铃由丝绳垂下，管下悬铃舌/风板
- 被敲响的铃发光 + 光晕涟漪扩散；风里飘过细碎花瓣/尘
- 构图：7根铃管高低错落横排，大面积留白在下部暗空

## 音频锚点（本次研的核心）

与墨韵/绒丝的 Karplus-Strong 弦音（谐波系列）拉开差异，用**加法合成非谐泛音**：

- 金属条/管泛音比：1, 2.76, 5.40, 8.93（LibreTexts Understanding Sound）
- 钟类泛音列：hum 0.5 / prime 1 / tierce 1.2 / quint 1.5 / nominal 2.0（McGee Bell Partials；JASA 2024 carillon 论文同）
- 设计：5个分音 [0.5, 1, 1.19, 2.76, 5.40]，高频分音衰减快（0.3-1s）、hum/prime衰减慢（4-6s）→ 敲击瞬间金属亮感，尾巴温暖
- 音阶：A小调五声 A3 C4 D4 E4 G4 A4 C5（管越长音越低）

## 交互设计

- 点击铃管 → 直接敲响
- 拖拽铃管 → 摆动（摆锤物理），松手后铃舌自撞
- 空白处横扫 → 掀起一阵风，全檐铃渐次响
- 风力滑杆控制环境风；自动阵风系统（4-9s随机）

## 物理模型

- 铃管：单摆（theta/omega，重力恢复+阻尼+风力矩）
- 铃舌：相对管底的一维弹簧振子 s，|s| > 管半径即碰撞 → 反弹 + 触发钟声（幅度∝碰撞速度）
- 风：基础风 + 阵风包络 + 每铃随机相位抖动

## 工具选择

纯手写 Canvas 单文件 HTML，零依赖。复用绒丝/墨韵的卷积混响 IR 生成模式。
