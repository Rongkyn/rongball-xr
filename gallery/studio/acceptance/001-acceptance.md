#### 2. 控制台潜在报错 — 3/5

逐项检查未定义变量和函数调用顺序：

- **[BUG] 粒子初始位置为 (0,0)**：`initParticles()` 在函数定义后立即调用（约第 280 行），此时 `W=0, H=0`（`resize()` 在文件末尾才调用）。所有粒子的 `x=Math.random()*0=0`，`y=Math.random()*0=0`。虽然粒子会在动画中逐渐漂移散开，但初始加载时左上角会有短暂的粒子聚集。`resize()` 不重新初始化粒子（仅进入冬季时才 `initParticles()`）。

- **[BUG] 山脉离屏缓存导致季节切换瞬断**：`drawMountains()` 的缓存失效条件为 `mountainCvSeason !== currentSeason`。但 `currentSeason` 在季节过渡动画结束时（`seasonT >= 1`）才更新为 `targetSeason`。在 2 秒过渡期间，`seasonConfig()` 正确返回插值颜色，但 `drawMountains` 因缓存命中始终绘制旧季节山脉。过渡结束瞬间 `currentSeason` 变更，缓存失效，山脉颜色突然跳变。与此同时，天空色调（tint wash）在平滑过渡，造成"天空在变、山脉不动、最后突然跳"的割裂感。

- **[BUG] 舍屋炊烟逐帧随机闪烁**：`drawHut()` 中炊烟绘制条件为 `Math.random()<0.02`，每帧独立随机。结果是炊烟以单帧（16ms）为单位随机闪现，而非持续动画。应使用基于时间的概率或持久状态。

- **[MINOR] 雾气颜色插值不完整**：`seasonConfig()` 在过渡期间对 `mist` 属性采用 `k < 0.5 ? f.mist : t.mist` 的硬切换，在过渡中点雾气颜色会跳变。虽然雾气本身 alpha 很低（0.06-0.12），影响较小。

- 其余变量和函数均在使用前定义，无 `undefined` 引用。`parseColor()` 正确处理 hex 和 rgb/rgba 格式。

## 发现的问题

### Blockers（必须修）

1. **山脉颜色季节切换瞬断**
   - 位置：`drawMountains()` 缓存逻辑 + `update()` 季节过渡逻辑
   - 原因：`mountainCvSeason` 仅在 `currentSeason` 变更时失效，而 `currentSeason` 在 2 秒过渡结束后才更新。过渡期间 `seasonConfig()` 返回的插值颜色被缓存忽略。
   - 影响：天空色调平滑过渡 2 秒后，山脉突然跳变，视觉割裂，直接违背"动效缓慢有机"和四季系统的核心体验。
   - 修复方向：将 `mountainCvSeason` 缓存键改为同时检查 `seasonT`（如当 `seasonT < 1` 时禁用缓存或按插值步进缓存），或在过渡期间降低缓存频率重绘山脉。

### Nice-to-have（建议改进）

1. **粒子初始位置为 (0,0)**
   - `initParticles()` 在 `resize()` 之前调用，W/H 均为 0。应在 `resize()` 末尾调用 `initParticles()`，或移除定义处的立即调用。

2. **舍屋炊烟逐帧随机闪烁**
   - `Math.random()<0.02` 应改为基于时间的持续动画（如用 `time` 和元素 `phase` 计算炊烟是否可见及位置），或给每个舍添加持久的炊烟状态。

3. **季节指示点触摸目标过小**
   - 10×10px 不满足移动端 44×44px 最小触摸区域建议。可增大点击区域（用 padding 扩大 hit area）或放大圆点。

4. **雾气颜色在过渡中点硬切换**
   - `seasonConfig()` 中 `mist` 用 `k < 0.5` 三元判断，应与其他颜色一样做字符串插值。

5. **墨色远近分层可更系统**
   - 远山建议使用 `INK.qing`/`INK.dan` 作为基调叠加季节色调，而非纯季节色，以强化"焦浓重淡清"的水墨层次感。

6. **宣纸纹理逐像素操作开销**
   - 高 DPI 屏 resize 时可能卡顿，可考虑降低噪声分辨率（如 1/2 分辨率再放大）或用 CSS `feTurbulence` 滤镜替代。

7. **来客 layout 参数未充分利用**
   - `layout.hasWater`/`hasShelter`/`hasLife` 已计算但未在 evaluate 中使用，可丰富来客判断逻辑（如隐士偏好有水有舍、行者偏好开阔无遮挡等）。

8. **印章字体跨平台一致性**
   - 建议将印章文字改为 Canvas 路径绘制或内嵌 SVG 路径，避免非苹果系统字体 fallback 影响印章风格。

## 复查（2026-08-13）

针对首轮验收报告中的 1 个 Blocker 和 2 项 Nice-to-have 修复进行定向复查。

### 1. Blocker — 山脉季节切换瞬断：✅ 通过

Maker 重构了山脉渲染架构，从"整层带色缓存"改为"白色形状蒙版 + 每帧 destination-in 染色"：

- **颜色逐帧跟随插值**：`buildMountainCache()` 仅生成 3 张白色形状蒙版（`mountainShapeLayers`）和 1 张山脊线缓存（`mountainLineCv`），不包含任何颜色信息。`drawMountains(cfg)` 每帧用 `cfg.mountain[li]`（即 `seasonConfig()` 返回的插值色）铺色，再通过 `destination-in` 与白色蒙版合成。季节过渡期间 `cfg.mountain` 每帧变化，山脉颜色随之平滑插值，不再有瞬断。
- **蒙版仅在 resize 时重建**：`buildMountainCache()` 由 `buildMountains()` 调用，而 `buildMountains()` 仅在 `resize()` 中触发。每帧仅执行 3 次 clearRect → fillRect → drawImage → drawImage（共约 12 次 Canvas 操作），性能开销极低。
- **过渡结束无跳变**：`seasonT` 从 0 到 1 连续变化，`cfg.mountain` 也连续变化；当 `seasonT>=1` 时 `currentSeason=targetSeason`，此时插值结果等于目标季节色，无数值跳变。`mountainTmpCv` 每帧 clearRect，不存在残留帧。
- 旧的 `mountainCv`/`mountainCvSeason` 缓存变量已完全移除，无遗留死代码。

### 2. 粒子初始位置：✅ 通过
