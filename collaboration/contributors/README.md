# 贡献者入口

本页帮助读者找到已有贡献，不是账号目录、权限表或当前接单名单。
研究按课题保存，作品保留原署名；贡献者可以轮流承担研究、制作、整合、审查角色。
独立研究可并存；共同成果按实际贡献署名，不强制形成同一结论。

| 贡献标签 | 可核对的贡献 | 从哪里继续 |
|---|---|---|
| Rongball / 绒球 | 根 README 署名的既有作品；共享池的维护记录 | [作品入口](../../README.md)、[POOL](../../gallery/works/lib/POOL.md) |
| dot | PR #3 的共同入口与独立水声源码比较 | [原始 PR #3](https://github.com/Rongkyn/rongball-xr/pull/3)、[研究](../../research/water-audio-comparison/README.md) |
| Codex（本次执行标签） | 本片合作请求、宿主读取流程与水声试点规程；以交付 PR 的实际 diff 为准 | [交接](../handoff.md)、[宿主读取](../host-pickup.md)、[试点](../../research/water-audio-comparison/pilot.md) |

这些条目不声明任何一方愿意接单、常驻在线、已接受其他人的研究或具有某项工具权限。
同一 GitHub 账号可能承载多个贡献者，账号一致不能证明是不同执行实例。
Codex 在本片仅指执行标签；尚未建立跨会话的独立作者身份，不追溯归入其他 Codex 会话成果。

新增或修订条目时给出贡献标签、本人公开描述（没有则留空）、真实产物链接和贡献证据。
可另加个人介绍页，但共同索引只保存链接。研究兴趣与能力声明由本人确认，勿替其他 Agent 编造。
真实参与记录分别保留 actor（署名）、host（运行平台）、run（可公开的执行编号）和来源事件；
不公开私人会话链接、账号细节或凭证。

联系从相关课题 Issue 开始，按[交接格式](../handoff.md)写明对象、版本与预期回复。
没有可用接收入口时，记录待接收；需要人工转交时只提供公开链接和简短任务。
本页不承担自动通知。
